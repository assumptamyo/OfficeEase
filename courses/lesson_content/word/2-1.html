Lesson 2.1

When information has more than one dimension, such as products against prices or tasks against dates, a paragraph cannot present it clearly. A table can. This lesson covers how to build a table, restructure it and format it so that the reader finds a value at a glance.

Learning objectives

By the end of this lesson you will be able to:

  • select the most suitable method of creating a table;
  • add, delete, merge and split rows, columns and cells;
  • apply a table style and control its style options;
  • make a long table readable across pages and perform simple calculations in it.

The anatomy of a table

Cell
A single box in the table, formed where a row meets a column. Each cell holds its own text and formatting.
Header row
The first row, containing the column titles. Word can format it differently and repeat it on every page.
Contextual tabs
When the cursor is inside a table, two extra tabs appear: Table Design for appearance and Layout for structure.

Creating a table

All methods begin at Insert > Table.

MethodHow it worksBest for
Grid selectorDrag across the grid of squares; the maximum is 10 columns by 8 rowsSmall tables, created quickly
Insert Table dialog boxType the exact number of columns and rows and choose the AutoFit behaviourLarger tables or precise column widths
Convert Text to TableTurns text separated by tabs or commas into a tableData that has already been typed or pasted
Excel SpreadsheetEmbeds a working Excel sheet in the pageTables that need real formulas

The AutoFit setting decides how column widths behave: Fixed Column Width keeps them as set, AutoFit to Contents shrinks or grows each column around its text, and AutoFit to Window stretches the table across the page.

Entering data and changing the structure

Press Tab to move to the next cell and Shift + Tab to move back. Pressing Tab in the last cell adds a new row, so a table grows as you type.

Structural changes are made on the Layout contextual tab:

  • Insert Above / Below / Left / Right adds a row or column next to the cursor.
  • Delete removes cells, rows, columns or the whole table.
  • Merge Cells joins the selected cells into one, typically for a title that spans several columns.
  • Split Cells divides one cell into several.
  • Distribute Rows / Columns makes the selected rows or columns equal in size.
Common mistakePressing Delete with a row selected clears the text but leaves the empty row. To remove the row itself use Layout > Delete > Delete Rows.

Formatting with table styles

The Table Design tab offers a gallery of ready-made styles such as Grid Table 4 - Accent 1. A style applies borders, shading and fonts in one step and keeps every table in the document consistent.

The Table Style Options check boxes tell the style which parts deserve special treatment. Header Row emphasises the first row, Banded Rows shades alternate rows so the eye can follow a line across, and Total Row emphasises the last row.

TipAlign text to the left and numbers to the right. Right-aligned figures line up by unit, which lets the reader compare them instantly.

Long tables and calculations

If a table runs onto a second page, the reader loses the column titles. Click in the header row and choose Layout > Repeat Header Rows; Word then prints the header at the top of every page automatically.

For simple arithmetic, click in the cell that should hold the result and choose Layout > Formula. Word proposes =SUM(ABOVE), which totals the numbers above the cell. Unlike Excel, the result does not recalculate by itself: select it and press F9 after changing any figure.

Worked example: a quarterly sales table

  1. Choose Insert > Table > Insert Table and request 5 columns and 6 rows.
  2. Type the column titles in the first row, then the data, moving with Tab.
  3. On Table Design, apply Grid Table 4 - Accent 1 and tick Header Row, Banded Rows and Total Row.
  4. In the last cell of each numeric column insert =SUM(ABOVE).
  5. Select the number cells and right-align them.

Key takeaways

  • The grid selector is quick but limited to 10 × 8; the Insert Table dialog box gives exact control.
  • Structure is changed on the Layout tab, appearance on the Table Design tab.
  • Repeat Header Rows keeps column titles visible on every page.
  • Word formulas such as =SUM(ABOVE) must be updated with F9.

Check your understanding

You need a table with 12 columns. Which creation method must you use, and why?

The Insert Table dialog box, because the grid selector cannot go beyond 10 columns.

What is the quickest way to add a row at the end of a table?

Place the cursor in the last cell and press Tab.

You change a figure and the total stays the same. What has been forgotten?

Word does not recalculate automatically. Select the formula result and press F9 to update it.
