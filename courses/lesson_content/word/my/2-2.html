သင်ခန်းစာ ၂.၂

ရုပ်ပုံများသည် စကားလုံးများ မတတ်နိုင်သည်ကို ရှင်းပြပြီး စာမျက်နှာတိုင်းတွင် ၎င်း၏ အမှတ်အသားကို မှတ်တမ်းတစ်ခုပေးသည်။ နှစ်ခုစလုံးသည် အယူအဆတစ်ခုအပေါ် နားလည်မှုပေါ်တွင် မူတည်သည်- အရာဝတ္ထုတစ်ခု စာသားနှင့် ဆက်စပ်နေပုံ အနေအထား။

သင်ယူမှုရည်ရွယ်ချက်များ

ဤသင်ခန်းစာ၏အဆုံးတွင် သင်လုပ်နိုင်သည်-

  • ပုံများ၊ ပုံသဏ္ဍာန်များနှင့် ပုံသဏ္ဍာန်များကို ထည့်သွင်းပြီး ပုံပျက်ခြင်းမရှိဘဲ အရွယ်အစားပြောင်းလဲပါ။
  • သင့်လျော်သော စာသားထုပ်ပိုးခြင်းရွေးချယ်မှုကို ရွေးချယ်ပြီး ၎င်း၏အကျိုးသက်ရောက်မှုကို ရှင်းပြပါ။
  • စာမျက်နှာနံပါတ်များပါရှိသော ခေါင်းစီးများနှင့် အောက်ခြေများကို ဖန်တီးပါ။
  • ပထမစာမျက်နှာ၊ ထူးဆန်းသောစာမျက်နှာများနှင့် စာမျက်နှာများအကြား ခေါင်းစီးများ ကွဲပြားသည်။

သရုပ်ဖော်ပုံများ ထည့်သွင်းခြင်း။

Insert tab ရှိ Illustrations အဖွဲ့သည် ရုပ်ပုံများ (ဖိုင်တစ်ခု သို့မဟုတ် အွန်လိုင်းမှ)၊ Shapes၊ Icons၊ SmartArt ပုံကြမ်းများနှင့် ဇယားများကို ပံ့ပိုးပေးပါသည်။ အရာဝတ္ထုတစ်ခုကို ရွေးချယ်သည့်အခါ၊ ဖြတ်တောက်ခြင်း၊ ပုံစံရေးဆွဲခြင်းနှင့် စီစဉ်ခြင်းအတွက် ကိရိယာများဖြစ်သည့် Picture Format ကဲ့သို့သော ဆက်စပ်တဲဘ်တစ်ခု ပေါ်လာပါသည်။

ပုံတစ်ပုံကို အရွယ်အစားပြောင်းရန်၊ ထောင့်လက်ကိုင်ကို ဆွဲယူပါ။ ထောင့်လက်ကိုင်များသည် အချိုးအစားများကို ထိန်းသိမ်းထားရန်၊ ဘေးဘက်လက်ကိုင်သည် ပုံကို ဆန့်ကာ ပုံပျက်စေသည်။

ထိပ်ဖျားပုံတွင်ပြသထားသည်များကိုဖော်ပြသည့် Alt Text (ပုံကို ညာကလစ်နှိပ်ပါ) ထည့်ပါ။ စခရင်စာဖတ်သူများသည် ၎င်းကို ကျယ်လောင်စွာဖတ်နိုင်သောကြောင့် စာရွက်စာတမ်းအား အမြင်အာရုံချို့တဲ့သောစာဖတ်သူများထံ အသုံးပြုနိုင်စေပါသည်။

စာသားထုပ်ပိုးခြင်း။

စာသားကို ထုပ်ပိုးခြင်း သည် အရာဝတ္တုတစ်ဝိုက်တွင် ပတ်၀န်းကျင်ရှိ စာသားစီးဆင်းပုံကို ဆုံးဖြတ်သည်။ ရွေးထားသည့်အရာ၏ဘေးရှိ Layout Options ခလုတ်ဖြင့် သို့မဟုတ် Picture Format > Wrap Text ဖြင့် သတ်မှတ်ပါ။

OptionBehaviourရိုးရိုးသုံးတယ်။
In Line with Textပုံသည် မျဉ်းကြောင်းရှိ စာလုံးကြီးတစ်ခုနှင့်တူသည်။ ဤသည်မှာ ပုံသေဖြစ်သည်။ပုံသည် စာပိုဒ်များကြားတွင် ရိုးရှင်းသော စာရွက်စာတမ်းများ
Squareစာသားသည် ပုံ၏စတုဂံပုံသဏ္ဍာန်ပတ်ပတ်လည်တွင် စီးဆင်းနေသည်။အစီရင်ခံစာများနှင့် သတင်းလွှာများ
Tightစာသားသည် ပုံ၏ တကယ့်အပြင်အဆင်ကို လိုက်နာသည်။ပွင့်လင်းသော နောက်ခံများဖြင့် ဖြတ်တောက်ထားသော ပုံများ
Top and Bottomပုံ၏အထက်တွင် စာသားရပ်တန့်ပြီး ၎င်းအောက်တွင် ပြန်လည်စတင်ပါ။ကျယ်ပြန့်သောကိန်းဂဏန်းများနှင့်ဇယားများ
Behind Textပုံအား စာရွက်စာတမ်း စာသားနောက်တွင် ထားရှိပြီး ၎င်းကို ကျော်သွားပါသည်။နောက်ခံများနှင့် သေးငယ်သော လိုဂိုများ
In Front of Textပုံသည် စာသားအပေါ်တွင် ပေါ်နေပြီး ၎င်းကို ဖုံးအုပ်ထားသည်။တံဆိပ်ခေါင်းများ၊ လက်မှတ်များနှင့် ထပ်ဆင့်များ

In Line with Text မှလွဲ၍ ရွေးချယ်မှုတိုင်းသည် ပုံအား လွတ်လွတ်လပ်လပ် ဆွဲယူနိုင်သော floating object ဖြစ်လာစေသည်။ ရေပေါ်အရာဝတ္တုအား ကျောက်ဆူးဖြင့် စာပိုဒ်တစ်ခုနှင့် တွဲထားသည်။ ထိုစာပိုဒ်သည် အခြားစာမျက်နှာသို့ ရွေ့သွားပါက၊ ရုပ်ပုံသည် ၎င်းနှင့်အတူ ရွေ့လျားနေသည်။

ဘုံအမှားinline ပုံတစ်ပုံကို ဆွဲဆွဲပြီး သင်အလိုရှိရာသို့ အဘယ်ကြောင့် မသွားနိုင်သည်ကို စူးစမ်းပါ။ လိုင်းပုံတစ်ပုံသည် စာသားတစ်ကြောင်းတည်းသာ ထိုင်နိုင်သည်။ ထုပ်ပိုးမှုကို စတုရန်း သို့မဟုတ် Tight သို့ အရင်ပြောင်းပါ။

ခေါင်းစီးများနှင့် အောက်ခြေများ

ခေါင်းစီး သည် စာမျက်နှာတစ်ခုစီ၏ အပေါ်ဘက်အနားသတ်ရှိ ဧရိယာဖြစ်ပြီး အောက်ခြေအနားသတ်ရှိ အောက်ခြေ ဧရိယာဖြစ်သည်။ စာရွက်စာတမ်းခေါင်းစဉ်၊ လိုဂို သို့မဟုတ် စာမျက်နှာနံပါတ်ကဲ့သို့သော စာမျက်နှာတိုင်းတွင် ထပ်ခါတလဲလဲ ဖော်ပြထားသည့် အကြောင်းအရာ။

  1. အပေါ် သို့မဟုတ် အောက်ခြေအနားသတ်တွင် နှစ်ချက်နှိပ်ပါ၊ သို့မဟုတ် Insert > Header သို့မဟုတ် Footer ကို ရွေးပါ။
  2. စာသားကို ရိုက်ထည့်ပါ သို့မဟုတ် ပုံတစ်ခု ထည့်ပါ။ သင်အလုပ်လုပ်နေစဉ် စာရွက်စာတမ်း၏ကိုယ်ထည်သည် မှိန်နေသည်။
  3. နံပါတ်တပ်ရန်အတွက်၊ Insert > Page Number ကိုရွေးချယ်ပြီး ရာထူးတစ်ခုကို ရွေးပါ။ Word သည် အလိုအလျောက် ရေတွက်သည့် အကွက်တစ်ခုကို ထည့်သွင်းသည်။
  4. စာကိုယ်စာသားကို နှစ်ချက်နှိပ်ပါ သို့မဟုတ် စာရွက်စာတမ်းသို့ ပြန်သွားရန် Esc ကိုနှိပ်ပါ။

စာရွက်စာတမ်းတစ်ခုအတွင်း ခေါင်းစီးများ ကွဲပြားသည်။

Header & Footer တက်ဘ်တွင် ပုံစံပြောင်းလဲသည့် အမှတ်အသားနှစ်ခုပါရှိသည်-

Different First Page
ပထမစာမျက်နှာသည် ၎င်း၏ကိုယ်ပိုင် ခေါင်းစီးနှင့် အောက်ခြေမှတ်စုကို ပေးသည်၊ ထို့ကြောင့် အဖုံးစာမျက်နှာတစ်ခုတွင် စာမျက်နှာနံပါတ်မပါစေရန် အများအားဖြင့် ဗလာချန်ထားသည်။
ကွဲပြားခြားနားသော ထူးထူးခြားခြား စာမျက်နှာများ
စာမျက်နှာနံပါတ်၏ အပြင်ဘက်အစွန်းတွင် ပုံနှိပ်ထားသော စာအုပ်ကဲ့သို့ ညာလက်စာမျက်နှာများအတွက် ခေါင်းစီးတစ်ခုနှင့် ဘယ်ဘက်စာမျက်နှာများအတွက် နောက်တစ်ခုအား ခွင့်ပြုပါ။

အခန်းများအကြား ကွဲပြားသည့် ခေါင်းစီးများသည် အပိုင်းခွဲများနှင့် Module 3 တွင်ပါရှိသော Link to Previous ဆက်တင်များ လိုအပ်သည်။

လုပ်ဆောင်ခဲ့သည့် ဥပမာ- ထုတ်ကုန်စာရွက်

  1. ထုတ်ကုန်ဓာတ်ပုံကို ထည့်သွင်းပြီး စာမျက်နှာအကျယ်၏ သုံးပုံတစ်ပုံခန့်သို့ လျှော့ချရန် ထောင့်လက်ကိုင်ကို ဆွဲယူပါ။
  2. ထုပ်ပိုးခြင်းကို Tight သို့ သတ်မှတ်ပြီး ဓာတ်ပုံကို ညာဖက်အနားသတ်သို့ ဆွဲယူပါ။ ဖော်ပြချက်သည် ၎င်းကို လှည့်ပတ်နေသည်။
  3. ကုမ္ပဏီလိုဂိုကို ထည့်ပါ၊ ၎င်းကို Behind Text ဟု သတ်မှတ်ပြီး နောက်ခံအဖြစ် လုပ်ဆောင်ရန် ၎င်းကို Picture Format > Color > Washout ဖြင့် အလင်းပေးပါ။
  4. အောက်ခြေအနားသတ်ကို နှစ်ချက်နှိပ်ပါ၊ အလယ်ဗဟိုပြုထားသော စာမျက်နှာနံပါတ်ကို ထည့်သွင်းပြီး Different First Page ကို အမှန်ခြစ်ပါ။

သော့ယူမှုများ

  • ၎င်းတို့၏အချိုးအစားများကို ထိန်းသိမ်းရန် ထောင့်များမှ ပုံများကို အရွယ်အစားပြောင်းပါ။
  • Wrapping သည် စာမျက်နှာကို စာသားနှင့် ရုပ်ပုံ မျှဝေပုံကို ဆုံးဖြတ်သည်။ စာသား၏နောက်ကွယ်တွင် ပုံကို စာသားအောက်တွင် ထားရှိပါ။
  • မျောနေသော အရာဝတ္ထုများကို စာပိုဒ်တစ်ခုတွင် ကျောက်ချပြီး ၎င်းနှင့် အတူ ခရီးသွားပါ။
  • စာမျက်နှာတိုင်းတွင် ခေါင်းစီးနှင့် အောက်ခြေအကြောင်းအရာသည် ထပ်ခါထပ်ခါ ဖြစ်နေသည်။ ပထမစာမျက်နှာနှင့် ဂဏန်း/တူ စာမျက်နှာများ ကွဲပြားနိုင်သည်။

သင်၏နားလည်မှုကိုစစ်ဆေးပါ။

Behind Text wrapping option ၏ ရည်ရွယ်ချက်ကား အဘယ်နည်း။

၎င်းသည် စာရွက်စာတမ်း စာသားနောက်ကွယ်တွင် ပုံကို နေရာချပေးသောကြောင့် စာသားသည် ၎င်းကို ကျော်သွားပါသည်။ နောက်ခံနှင့် အားနည်းသော လိုဂိုများအတွက် အသုံးပြုသည်။

၎င်းအပေါ်တွင် စာသားထည့်သည့်အခါတိုင်း ဓာတ်ပုံသည် နောက်စာမျက်နှာသို့ ခုန်သွားပါသည်။ ဘာကြောင့်လဲ?

၎င်းကို စာပိုဒ်တစ်ခုတွင် ကျောက်ချထားပြီး၊ ထိုစာပိုဒ်သည် နောက်စာမျက်နှာသို့ ရွှေ့ထားသည်။ ပုံသည် ၎င်း၏အုတ်မြစ်ကို လိုက်နာသည်။

မျက်နှာဖုံးစာမျက်နှာပေါ်တွင် စာမျက်နှာနံပါတ်ကို မည်ကဲ့သို့ တားဆီးမည်နည်း။

ခေါင်းစီး သို့မဟုတ် အောက်ခြေမှတ်စုကိုဖွင့်ပြီး ခေါင်းစီးနှင့်အောက်ခြေရှိ မတူကွဲပြားသော ပထမစာမျက်နှာကို အမှတ်ခြစ်ပါ။
