သင်ခန်းစာ ၅.၂

အရေးကြီးစာရွက်စာတမ်းများကို လူတစ်ဦးမှ ရေးသားခဲပါသည်။ စာချုပ်များ၊ အစီရင်ခံစာများနှင့် မူဝါဒများသည် စာရေးဆရာများ၊ သုံးသပ်သူများနှင့် အတည်ပြုသူများကြားတွင် ဖြတ်သန်းပါသည်။ ပြန်လည်သုံးသပ်ခြင်းတက်ဘ် သည် အဆိုပါလုပ်ငန်းစဉ်ကို ပွင့်လင်းမြင်သာအောင်ပြုလုပ်ထားသောကြောင့် ပြောင်းလဲမှုတိုင်းကို မြင်နိုင်၊ အရင်းခံပြီး နောက်ပြန်လှည့်နိုင်ကာ နောက်ဆုံးဗားရှင်းကို မလိုလားအပ်သော အပြောင်းအလဲများမှ ကာကွယ်ပေးပါသည်။

သင်ယူမှုရည်ရွယ်ချက်များ

ဤသင်ခန်းစာ၏အဆုံးတွင် သင်လုပ်နိုင်သည်-

  • တည်းဖြတ်မှုများကို Track Changes ဖြင့် မှတ်တမ်းတင်ပြီး ၎င်းတို့ကို ပြသပုံကို ရွေးချယ်ပါ။
  • အပြောင်းအလဲများကို လက်ခံခြင်း သို့မဟုတ် ငြင်းပယ်ခြင်းနှင့် မှတ်ချက်များကို စီမံခန့်ခွဲခြင်း၊
  • စာရွက်စာတမ်းတစ်ခု၏ ဗားရှင်းနှစ်ခုကို နှိုင်းယှဉ်ပါ။
  • တည်းဖြတ်ခြင်းကို ကန့်သတ်ပြီး စာရွက်စာတမ်းတစ်ခုကို စကားဝှက်ဖြင့် ကာကွယ်ပါ။

Track Changes

Track Changes ကို ဖွင့်ထားသည့်အခါ၊ Word သည် ၎င်းကို ရိုးရိုးရှင်းရှင်း ထည့်သွင်းခြင်းအစား ထည့်သွင်းခြင်း၊ ဖျက်ခြင်း၊ ရွှေ့ခြင်းနှင့် ဖော်မတ်ချခြင်း ပြောင်းလဲမှုတိုင်းကို မှတ်တမ်းတင်ပါသည်။ ပြောင်းလဲမှုတစ်ခုစီတိုင်းကို ဝေဖန်သုံးသပ်သူ၏အမည်နှင့် အချိန်ဖြင့် အမှတ်အသားပြုထားပြီး ဝေဖန်သူတိုင်းကို မတူညီသောအရောင်တစ်ခုစီပေးထားသည်။ ၎င်းကို Review > Track Changes သို့မဟုတ် Ctrl + Shift + E ဖြင့် ဖွင့် သို့မဟုတ် ပိတ်ပါ။

Display for Review စာရင်းသည် သင်မြင်သောအရာကို ထိန်းချုပ်သည်။ မှတ်တမ်းတင်ထားသည်ကို မပြောင်းလဲပါ။

Viewဘာကိုပြတာလဲ။အဲဒါကိုသုံးပါ။
Simple Markupပြောင်းလဲမှုတစ်ခုစီဘေးရှိ အနားသတ်တွင် အနီရောင်မျဉ်းဖြင့် တည်းဖြတ်ထားသော စာသားအပြောင်းအလဲတွေ ဘယ်မှာရှိတယ်ဆိုတာ သိရင်းနဲ့ စာတမ်းကို အေးအေးဆေးဆေး ဖတ်ပါ။
All Markupထည့်သွင်းမှုတိုင်းကို မျဉ်းသားပြီး ဖျက်လိုက်တိုင်း ဖြတ်သွားသည်ပြောင်းလဲမှုတစ်ခုစီကို အသေးစိတ်စစ်ဆေးပါ။
No Markupပြောင်းလဲမှုအားလုံးကို လက်ခံပါက စာရွက်စာတမ်းကို ကြည့်ရမည်ဖြစ်ပါသည်။နောက်ဆုံးရလဒ်ကို ကြိုကြည့်ပါ။
Originalစာရွက်စာတမ်းက အရင်အတိုင်းပဲနော်။အစတွင် စာသားပြောသည်ကို စစ်ဆေးပါ။
အရေးကြီးတယ်။No Markup သည် ပြောင်းလဲမှုများကိုသာ ဖုံးကွယ်ထားသည်။ ၎င်းတို့ကို ဖိုင်ထဲတွင် သိမ်းဆည်းထားဆဲဖြစ်သည်။ စာရွက်စာတမ်းကို လက်ခံရရှိသူတိုင်းသည် All Markup သို့ ပြောင်းနိုင်ပြီး ဖျက်လိုက်သော စာသားနှင့် မှတ်ချက်များကို ဖတ်နိုင်သည်။ နောက်ဆုံးဗားရှင်းမပို့မီ ပြောင်းလဲမှုတိုင်းကို လက်ခံ သို့မဟုတ် ငြင်းပယ်ပါ။

အပြောင်းအလဲများကို လက်ခံခြင်းနှင့် ငြင်းပယ်ခြင်း။

စာရွက်စာတမ်းပိုင်ရှင်သည် မည်သည့်ပြောင်းလဲမှုများ ရှိနေသည်ကို ဆုံးဖြတ်သည်။

  1. All Markup သို့ပြောင်းပြီး စာရွက်စာတမ်း၏အစတွင် နှိပ်ပါ။
  2. ပြောင်းလဲမှုတစ်ခုမှ နောက်တစ်ခုသို့ ပြောင်းရန် အပြောင်းအလဲများအဖွဲ့တွင် Next နှင့် Previous ကို အသုံးပြုပါ။
  3. အပြောင်းအလဲကို အမြဲတမ်းပြုလုပ်ရန် Accept ကို နှိပ်ပါ သို့မဟုတ် မူရင်းစာသားကို ပြန်လည်ရယူရန် Reject ။
  4. မြန်မြန်ပြီးရန်၊ ခလုတ်နှစ်ခုစလုံးအောက်ရှိ မြှားကိုဖွင့်ပြီး Accept All Changes သို့မဟုတ် Reject All Changes ကို ရွေးပါ။

မှတ်ချက်များ

မှတ်ချက်သည် စာသားအပိုင်းတစ်ခုနှင့် တွဲထားသော မှတ်စုတစ်ခုဖြစ်သည်။ ၎င်းသည် စာရွက်စာတမ်းကို မပြောင်းလဲဘဲ မေးခွန်းတစ်ခုမေးခြင်း သို့မဟုတ် အကြံပြုချက်တစ်ခု ပြုလုပ်သည်။ စာသားကို ရွေးပြီး Review > New Comment ကို ရွေးပါ သို့မဟုတ် Ctrl + Alt + M ကို နှိပ်ပါ။

လုပ်ဖော်ကိုင်ဖက်များသည် မှတ်ချက်တစ်ခုအောက်တွင် စာပြန်နိုင်သည် ၊ စာတွဲတစ်ခုဖွဲ့ကာ အမှတ်အသားပြုပြီး ဖြေရှင်းပြီးသည်နှင့် အမှတ်အသားပြုနိုင်သည်။ မှတ်ချက်များကို တစ်ဦးချင်းစီ ဖျက်ပါ သို့မဟုတ် မထုတ်ဝေမီ စာရွက်စာတမ်းရှိ မှတ်ချက်များအားလုံးကို ဖျက်ပါ ကို အသုံးပြုပါ။

ထိပ်ဖျားစာသားဘာပြောသင့်သည်ကို သိသောအခါ၊ နှင့် စာရေးဆရာကို ဆုံးဖြတ်စေလိုသောအခါတွင် မှတ်ချက်ပေးသည့် အပြောင်းအလဲကို အသုံးပြုပါ။

စာရွက်စာတမ်းများကို နှိုင်းယှဉ်ခြင်း။

တစ်စုံတစ်ယောက်သည် Track Changes ကိုမဖွင့်ဘဲ စာရွက်စာတမ်းတစ်ခုကို တည်းဖြတ်ပါက၊ Review > Compare သည် ကွဲပြားမှုများကို ပြန်လည်ရရှိမည်ဖြစ်သည်။

Compare
မူရင်းနှင့် ပြန်လည်ပြင်ဆင်ထားသော စာရွက်စာတမ်းတစ်ခုယူကာ ကွဲပြားမှုတိုင်းကို ခြေရာခံထားသော ပြောင်းလဲမှုတစ်ခုအဖြစ် ပေါ်လာသည့် တတိယစာရွက်စာတမ်းကို ထုတ်လုပ်သည်။ ၎င်းကို တစ်ခါတစ်ရံတွင် တရားဝင် blackline ဟုခေါ်သည်။
Combine
ဝေဖန်သုံးသပ်သူအများအပြား၏ ခြေရာခံထားသော အပြောင်းအလဲများကို ၎င်းတို့၏ကိုယ်ပိုင်မိတ္တူတွင် လုပ်ဆောင်နေသူတိုင်းကို စာရွက်စာတမ်းတစ်ခုတည်းအဖြစ် ပေါင်းစည်းပါ။

စာရွက်စာတမ်းကိုကာကွယ်ခြင်း။

ProtectionWhereEffect
Restrict Editingသုံးသပ်ချက် တက်ဘ်ခြေရာခံထားသော အပြောင်းအလဲများ၊ မှတ်ချက်များ၊ ဖောင်များဖြည့်ခြင်း သို့မဟုတ် စာဖတ်ခြင်းအတွက်သာ အခြားသူများကို ကန့်သတ်ထားသည်။ စကားဝှက်တစ်ခုသည် ၎င်းတို့အား ၎င်းကို ပိတ်ပစ်ခြင်းကို ရပ်တန့်စေသည်။
Encrypt with PasswordFile > Info > Protect Documentစကားဝှက်မပါဘဲ ဖိုင်ကို ဖွင့်၍မရပါ။
Mark as FinalFile > Info > Protect Documentပြီးဆုံးကြောင်း အချက်ပြမှုအဖြစ် ဖိုင်ကို ဖတ်ရန်-သပ်သပ် ဖွင့်သည်။ ယဉ်ကျေးသိမ်မွေ့မှု၊ မည်သူမဆို Edit Anyway ကို ရွေးချယ်နိုင်ပါသည်။
အရေးကြီးတယ်။Word မေ့သွားသော ကုဒ်ဝှက်ထားသော စကားဝှက်ကို ပြန်မရနိုင်ပါ။ ဖိုင်ကို မပိတ်မီ လုံခြုံသောနေရာတွင် သိမ်းဆည်းပါ။

လုပ်ဆောင်ခဲ့သည့် ဥပမာ- ပေးသွင်းသူ စာချုပ်ကို ပြန်လည်သုံးသပ်ခြင်း။

  1. Track Changes ကိုဖွင့်ရန် Ctrl + Shift + E ကိုနှိပ်ပါ၊ ထို့နောက် စာပိုဒ်သုံးခုကို ပြင်ပါ။
  2. ငွေပေးချေမှု သက်တမ်းကို ရွေးချယ်ပြီး ပေးသွင်းသူအား အတည်ပြုရန် တောင်းဆိုသော မှတ်ချက်တစ်ခု ထည့်ပေးပါ။
  3. When the contract returns, step through the changes with Next, accepting or rejecting each one.
  4. မှတ်ချက်များကို ဖြေရှင်းပြီး ဖျက်ပြီးနောက် ဘာမှမကျန်တော့ကြောင်း All Markup တွင် စစ်ကြည့်ပါ။
  5. သဘောတူထားသည့် စာသားကို မပြောင်းလဲနိုင်စေရန် စကားဝှက်ဖြင့် Restrict Editing ကို အသုံးပြုပါ။

သော့ယူမှုများ

  • Ctrl + Shift + E ခလုတ်များသည် Track Changes၊ မည်သည် မည်သည့်အချိန်တွင် ပြောင်းလဲသွားသည်ကို မှတ်တမ်းတင်သည်။
  • Markup အမြင်များသည် သိမ်းဆည်းထားသည့်အရာကိုမဟုတ်ဘဲ သင်မြင်သောအရာကို ပြောင်းလဲစေပါသည်။ နောက်ဆုံးမိတ္တူမပို့မီ ပြောင်းလဲမှုအားလုံးကို ရှင်းလင်းပါ။
  • ဗားရှင်းနှစ်ခုကြား ကွာခြားချက်ကို နှိုင်းယှဉ်ဖော်ပြသည်။ သုံးသပ်သူများ၏ တည်းဖြတ်မှုများ အများအပြားကို ပေါင်းစပ်ပေါင်းစပ်ပါ။
  • တည်းဖြတ်ခြင်းကို ကန့်သတ်ရန် အခြားသူများ ပြောင်းလဲနိုင်သည့်အရာများကို ကန့်သတ်ပါ။ ဖိုင်ကိုဖွင့်နိုင်သည့်သူအား စကားဝှက်ထိန်းချုပ်မှုများဖြင့် စာဝှက်ပါ။

သင်၏နားလည်မှုကိုစစ်ဆေးပါ။

သင်သည် No Markup သို့ပြောင်းပြီး စာရွက်စာတမ်းကို အီးမေးလ်ပို့ပါ။ လက်ခံသူက သင်ဖျက်လိုက်တဲ့အရာကို မြင်နိုင်ပါသလား။

ဟုတ်ကဲ့။ အပြောင်းအလဲများကိုသာ မှတ်သားထားခြင်းမရှိပါ။ လက်ခံသူသည် All Markup ကို ရွေးချယ်ပြီး ၎င်းတို့ကို ဖတ်နိုင်သည်။ အပြောင်းအလဲတိုင်းကို ဦးစွာလက်ခံပါ သို့မဟုတ် ငြင်းပယ်ပါ။

လုပ်ဖော်ကိုင်ဖက်တစ်ဦးက သင့်အစီရင်ခံစာကို ခြေရာခံခြင်းမရှိဘဲ တည်းဖြတ်ခဲ့သည်။ သူတို့ပြောင်းလဲသွားတာကို သင်ဘယ်လိုသိနိုင်မလဲ။

ပြန်လည်သုံးသပ်ခြင်းကို အသုံးပြုပါ > သင့်မူရင်းနှင့် ၎င်းတို့၏ ပြန်လည်ပြင်ဆင်ထားသောဖိုင်ကို နှိုင်းယှဉ်ပါ။ Word သည် ကွဲပြားမှုတိုင်းကို ခြေရာခံထားသော ပြောင်းလဲမှုအဖြစ် ပြသသည်။

Mark အဖြစ် Final သည် အဘယ်ကြောင့် လုံခြုံရေးအင်္ဂါရပ်မဟုတ်သနည်း။

၎င်းသည် မက်ဆေ့ချ်တစ်ခုသာ ပြသပြီး ဖိုင်ကို ဖတ်ရန်သာ ထုတ်ပေးသည်။ မည်သည့်စာဖတ်သူမဆို Edit Anyway ကိုနှိပ်ပြီး စာရွက်စာတမ်းကို ပြောင်းလဲနိုင်သည်။
