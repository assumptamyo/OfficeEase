သင်ခန်းစာ ၂.၁

ကုန်ပစ္စည်းများ စျေးနှုန်းများ သို့မဟုတ် ရက်စွဲများနှင့် ဆန့်ကျင်သည့် အလုပ်များ ကဲ့သို့သော အတိုင်းအတာတစ်ခုထက်ပိုသော အချက်အလက်များ ရှိပါက စာပိုဒ်တစ်ခုသည် ၎င်းကို ရှင်းလင်းစွာ မတင်ပြနိုင်ပါ။ စားပွဲ တစ်လုံး။ ဤသင်ခန်းစာတွင် ဇယားတစ်ခုတည်ဆောက်ပုံ၊ ၎င်းကို ပြန်လည်ဖွဲ့စည်းပုံနှင့် ပုံစံချခြင်းတို့ကို စာဖတ်သူက တစ်ချက်ကြည့်လိုက်ခြင်းဖြင့် တန်ဖိုးတစ်ခုကို တွေ့ရှိနိုင်စေရန် အကျုံးဝင်ပါသည်။

သင်ယူမှုရည်ရွယ်ချက်များ

ဤသင်ခန်းစာ၏အဆုံးတွင် သင်လုပ်နိုင်သည်-

  • ဇယားတစ်ခုဖန်တီးရန် အသင့်တော်ဆုံးနည်းလမ်းကို ရွေးချယ်ပါ။
  • အတန်းများ၊ ကော်လံများနှင့် ဆဲလ်များကို ထည့်ခြင်း၊ ဖျက်ခြင်း၊ ပေါင်းစည်းခြင်း၊
  • ဇယားစတိုင်ကိုအသုံးပြုပြီး ၎င်း၏စတိုင်ရွေးချယ်စရာများကို ထိန်းချုပ်ပါ။
  • စာမျက်နှာများတစ်လျှောက် ဖတ်နိုင်သော ဇယားရှည်တစ်ခုကို ဖန်တီးပြီး ၎င်းတွင် ရိုးရှင်းသော တွက်ချက်မှုများကို လုပ်ဆောင်ပါ။

စားပွဲတစ်ခု၏ခန္ဓာဗေဒ

Cell
အတန်းတစ်ခုသည် ကော်လံတစ်ခုနှင့် ဆုံသည့်နေရာတွင် ဖွဲ့စည်းထားသော ဇယားရှိ အကွက်တစ်ခု။ ဆဲလ်တစ်ခုစီသည် ၎င်း၏ကိုယ်ပိုင်စာသားနှင့် ဖော်မတ်ချခြင်းကို ကိုင်ဆောင်ထားသည်။
ခေါင်းစီးအတန်း
ကော်လံခေါင်းစဉ်များပါဝင်သော ပထမတန်း။ Word သည် ၎င်းကို ကွဲပြားစွာဖော်မတ်နိုင်ပြီး စာမျက်နှာတိုင်းတွင် ၎င်းကို ထပ်လုပ်နိုင်သည်။
ဆက်စပ်တဲဘ်များ
cursor သည် စားပွဲတစ်ခုအတွင်း၌ အပိုတဘ်နှစ်ခုပေါ်လာသည်- အသွင်အပြင်အတွက် Table Design နှင့် ဖွဲ့စည်းပုံအတွက် Layout။

စားပွဲတစ်ခုဖန်တီးခြင်း။

နည်းလမ်းအားလုံး Insert > Table တွင် စတင်သည်။

Methodဘယ်လိုအလုပ်လုပ်လဲ။Best for
ဇယားကွက်ရွေးချယ်မှုလေးထောင့်ဇယားကွက်ကို ဖြတ်၍ ဆွဲပါ။ အများဆုံးမှာ ကော်လံ ၈ တန်းဖြင့် ၁၀ ကြောင်းဖြစ်သည်။စားပွဲငယ်များ၊ အမြန်ဖန်တီးထားသည်။
ဇယားကွက်ကို ထည့်သွင်းပါ။ကော်လံများနှင့် အတန်းအရေအတွက်အတိအကျကို ရိုက်ထည့်ပြီး AutoFit အပြုအမူကို ရွေးချယ်ပါ။ပိုကြီးသောဇယားများ သို့မဟုတ် တိကျသောကော်လံအကျယ်များ
Convert Text to Tableတဘ်များ သို့မဟုတ် ကော်မာများ ခြားထားသော စာသားကို ဇယားတစ်ခုအဖြစ် ပြောင်းသည်။စာရိုက်ပြီးသော သို့မဟုတ် ကူးထည့်ထားသည့်ဒေတာ
Excel Spreadsheetစာမျက်နှာတွင် အလုပ်လုပ်သော Excel စာရွက်ကို မြှုပ်ထားသည်။ဖော်မြူလာအစစ်အမှန်များ လိုအပ်သောဇယားများ

AutoFit ဆက်တင်သည် ကော်လံများ၏ အကျယ်ကို မည်ကဲ့သို့ ပြုမူသည်ကို ဆုံးဖြတ်သည်- Fixed Column Width ၎င်းတို့ကို သတ်မှတ်အတိုင်း ထားရှိသည်၊ AutoFit to Contents ၎င်း၏ စာသားတစ်ဝိုက်တွင် ကော်လံတစ်ခုစီကို ကျုံ့ သို့မဟုတ် ကြီးထွားစေပြီး AutoFit to Window ဇယားကို စာမျက်နှာတစ်လျှောက် ဆန့်သည်။

ဒေတာထည့်သွင်းခြင်းနှင့် ဖွဲ့စည်းပုံကို ပြောင်းလဲခြင်း။

နောက်ဆဲလ်သို့ ရွှေ့ရန် Tab ကို နှိပ်ပြီး ပြန်ရွှေ့ရန် Shift + Tab ။ နောက်ဆုံးဆဲလ်ရှိ Tab ကို နှိပ်ခြင်းဖြင့် အတန်းအသစ်တစ်ခု ထပ်ထည့်သည်၊ ထို့ကြောင့် သင်ရိုက်သည်နှင့်အမျှ ဇယားတစ်ခု ကြီးထွားလာသည်။

ဖွဲ့စည်းပုံပြောင်းလဲမှုများကို Layout contextual တက်ဘ်တွင် ပြုလုပ်သည်-

  • အထက် / အောက် / ဘယ် / ညာ ထည့်ပါ သည် cursor ဘေးတွင် အတန်း သို့မဟုတ် ကော်လံကို ထည့်သည်။
  • Delete သည် ဆဲလ်များ၊ အတန်းများ၊ ကော်လံများ သို့မဟုတ် ဇယားတစ်ခုလုံးကို ဖယ်ရှားသည်။
  • Merge Cells သည် ပုံမှန်အားဖြင့် ကော်လံများစွာကို ဖြန့်ကျက်သော ခေါင်းစဉ်အတွက် ရွေးချယ်ထားသောဆဲလ်များကို တစ်ခုထဲသို့ ပေါင်းထည့်သည်။
  • Split Cells သည် ဆဲလ်တစ်ခုကို အများအပြားအဖြစ် ပိုင်းခြားထားသည်။
  • Distribute Rows / Columns သည် ရွေးချယ်ထားသော အတန်းများ သို့မဟုတ် ကော်လံများကို အရွယ်အစား ညီစေသည်။
ဘုံအမှားရွေးချယ်ထားသောအတန်းတစ်ခုဖြင့် Delete ကိုနှိပ်ခြင်းဖြင့် စာသားကိုရှင်းလင်းစေသော်လည်း အတန်းအလွတ်ကို ချန်ထားသည်။ အတန်းကို ဖယ်ရှားရန် Layout > Delete > Delete Rows ကို အသုံးပြုပါ။

ဇယားပုံစံများဖြင့် ဖော်မတ်လုပ်ခြင်း။

Table Design တက်ဘ်သည် Grid Table 4 - Accent 1 ကဲ့သို့သော အဆင်သင့်လုပ်ထားသော ပုံစံများကို ပြခန်းတစ်ခု ပေးပါသည်။ စတိုင်တစ်ခုသည် အဆင့်တစ်ဆင့်တွင် ဘောင်များ၊ အရိပ်ထိုးခြင်းနှင့် ဖောင့်များကို သက်ရောက်ပြီး စာရွက်စာတမ်းရှိ ဇယားတိုင်းကို တသမတ်တည်းဖြစ်စေသည်။

Table Style Options check box များသည် အထူးကုသမှုနှင့် ထိုက်တန်သည့် အစိတ်အပိုင်းများကို ဖော်ပြသည်။ Header Row သည် ပထမတန်းကို အလေးပေးသည်၊ Banded Rows သည် အတန်းများကို အရိပ်များပေးကာ မျက်လုံးသည် မျဉ်းကြောင်းတစ်ကြောင်းအတိုင်း လိုက်နိုင်စေရန်နှင့် Total Row နောက်ဆုံးအတန်းကို အလေးပေးသည်။

ထိပ်ဖျားစာသားကို ဘယ်ဘက်နှင့် ဂဏန်းများကို ညာဘက်သို့ ညှိပါ။ ညာဖက်ညှိထားသော ကိန်းဂဏာန်းများကို ယူနစ်အလိုက် တန်းစီစေပြီး စာဖတ်သူကို ချက်ချင်း နှိုင်းယှဉ်နိုင်စေပါသည်။

စားပွဲရှည်များနှင့် တွက်ချက်မှုများ

ဇယားတစ်ခုသည် ဒုတိယစာမျက်နှာသို့ လည်ပတ်နေပါက စာဖတ်သူသည် ကော်လံခေါင်းစဉ်များ ဆုံးရှုံးသွားမည်ဖြစ်သည်။ ခေါင်းစီးအတန်းကို နှိပ်ပြီး Layout > Repeat Header Rows ကို ရွေးပါ။ Word ထို့နောက် စာမျက်နှာတိုင်း၏ထိပ်တွင် ခေါင်းစီးကို အလိုအလျောက် ပရင့်ထုတ်သည်။

ရိုးရှင်းသောဂဏန်းသင်္ချာအတွက်၊ ရလဒ်ကိုထိန်းထားသင့်သောဆဲလ်တွင် နှိပ်ပြီး Layout > Formula ကိုရွေးချယ်ပါ။ Word သည် ဆဲလ်အထက်ရှိ ဂဏန်းများ စုစုပေါင်း =SUM(ABOVE) ကို အဆိုပြုသည်။ Excel နှင့် မတူဘဲ၊ ရလဒ်သည် သူ့ဘာသာသူ ပြန်မတွက်တတ်ပါ- ပုံတစ်ခုခုကို ပြောင်းလဲပြီးနောက် ၎င်းကို ရွေးချယ်ပြီး F9 ကို နှိပ်ပါ။

လုပ်ဆောင်ခဲ့သည့် ဥပမာ- သုံးလပတ် အရောင်းဇယား

  1. Insert > Table > Insert Table ကိုရွေးပြီး ကော်လံ 5 ခုနှင့် 6 တန်း တောင်းဆိုပါ။
  2. ပထမအတန်းရှိ ကော်လံခေါင်းစဉ်များကို ရိုက်ထည့်ပါ၊ ထို့နောက် ဒေတာကို Tab ဖြင့် ရွှေ့ပါ။
  3. Table Design တွင်၊ Grid Table 4 - Accent 1 ကိုအသုံးပြုပြီး Header Row၊ Banded Rows နှင့် Total Row ကို အမှန်ခြစ်ပေးပါ။
  4. ဂဏန်းကော်လံတစ်ခုစီ၏ နောက်ဆုံးဆဲလ်တွင် =SUM(ABOVE) ကို ထည့်သွင်းပါ။
  5. နံပါတ်ဆဲလ်များကို ရွေးပြီး ၎င်းတို့ကို ညာဖက်ညှိပါ။

သော့ယူမှုများ

  • ဇယားကွက်ရွေးချယ်မှုသည် မြန်ဆန်သော်လည်း 10 × 8 တွင် ကန့်သတ်ထားသည်။ Insert Table dialog box သည် အတိအကျ ထိန်းချုပ်မှုကို ပေးသည်။
  • Layout tab တွင်ဖွဲ့စည်းပုံ၊ Table Design တက်ဘ်တွင်ပေါ်လာသည်။
  • ခေါင်းစီးအတန်းများကို ပြန်လုပ်ခြင်းသည် စာမျက်နှာတိုင်းတွင် ကော်လံခေါင်းစဉ်များကို မြင်နိုင်စေသည်။
  • =SUM(ABOVE) ကဲ့သို့သော ဖော်မြူလာ Word ခုကို F9 ဖြင့် မွမ်းမံရပါမည်။

သင်၏နားလည်မှုကိုစစ်ဆေးပါ။

ကော်လံ ၁၂ ခုပါသော ဇယားတစ်ခု လိုအပ်ပါသည်။ မည်သည့်ဖန်တီးမှုနည်းလမ်းကို သင်အသုံးပြုရမည်၊ အဘယ်ကြောင့်နည်း။

ဇယားကွက်ရွေးချယ်မှုစနစ်သည် ကော်လံ 10 ခုထက်မကျော်လွန်နိုင်သောကြောင့် ဇယားကွက်ထည့်သွင်းခြင်း

ဇယားတစ်ခု၏အဆုံးတွင် အတန်းတစ်ခုကို အမြန်ထည့်ရန် အဘယ်နည်း။

cursor ကို နောက်ဆုံးဆဲလ်တွင် ထည့်ပြီး Tab ကိုနှိပ်ပါ။

သင်သည် ကိန်းဂဏန်းတစ်ခုကို ပြောင်းလဲလိုက်ပြီး စုစုပေါင်းသည် တူညီနေမည်ဖြစ်သည်။ ဘာတွေ မေ့သွားခဲ့ပြီလဲ။
