သင်ခန်းစာ ၁.၁

သင်ထုတ်လုပ်ဖူးသမျှ စာရွက်စာတမ်းတိုင်းနီးပါးသည် မျက်နှာပြင်တစ်ခုတွင် ပုံသဏ္ဍာန်ရှိသည်- Home တက်ဘ်။ ဤသင်ခန်းစာတွင် Word သည် ၎င်း၏ ညွှန်ကြားချက်များကို မည်ကဲ့သို့ စီမံပုံနှင့် စာလုံးများနှင့် စာပိုဒ်များ၏ အသွင်အပြင်ကို အစမ်းမှားခြင်းထက် တမင်တကာ ထိန်းချုပ်နည်းကို ရှင်းပြထားသည်။

သင်ယူမှုရည်ရွယ်ချက်များ

ဤသင်ခန်းစာ၏အဆုံးတွင် သင်လုပ်နိုင်သည်-

  • Word ဝင်းဒိုး၏ အစိတ်အပိုင်းများကို ခွဲခြားသတ်မှတ်ပြီး Ribbon ကို မည်သို့ဖွဲ့စည်းကြောင်း ရှင်းပြပါ။
  • character formatting နှင့် paragraph formatting ကို ပိုင်းခြားပါ။
  • Ribbon နှင့် ကီးဘုတ်နှစ်ခုလုံးကို အသုံးပြု၍ ဖောင့်၊ အရွယ်အစား၊ အလေးပေးမှု၊ ချိန်ညှိမှုနှင့် အကွာအဝေးကို အသုံးပြုပါ။
  • မလိုလားအပ်သော ဖော်မတ်ကို သန့်ရှင်းစွာ ဖယ်ရှားပါ။

Word ဝင်းဒိုးကို မည်ကဲ့သို့ ဖွဲ့စည်းထားသည်။

Word သည် ၎င်း၏ ရာနှင့်ချီသော အမိန့်များကို အဆင့်သုံးဆင့်ဖြင့် အုပ်စုဖွဲ့ပါ။ အထက်တန်းအဆင့်ကို နားလည်ခြင်းဆိုသည်မှာ မည်သည့်နေရာတွင်ရှိသည်ကို ကျက်မှတ်ခြင်းထက် ဖြစ်သင့်သည့် မည်သည့်အမိန့်ကိုမဆို ရှာဖွေနိုင်သည်ကို ဆိုလိုသည်။

Ribbon
ပြတင်းပေါက်၏ထိပ်တွင်ရှိသော command များ၏တီးဝိုင်း။ ၎င်းသည် မီနူးများနှင့် ကိရိယာဘားဟောင်းများကို အစားထိုးသည်။
Tab
Ribbon အလုပ်၏ အဆင့်တစ်ခုအတွက် ရည်ရွယ်ထားသော စာမျက်နှာတစ်ခု- တည်းဖြတ်ရန်အတွက် Home၊ အရာဝတ္ထုများထည့်ခြင်းအတွက် Insert၊ စာမျက်နှာတည်ဆောက်မှုအတွက် Layout စသည်တို့ဖြစ်သည်။
Group
တက်ဘ်တစ်ခုအတွင်း ဆက်စပ်သော ညွှန်ကြားချက်များ အစုအဝေးဟု အညွှန်းတပ်ထားသည်။ Home တက်ဘ်တွင် Clipboard၊ ဖောင့်၊ စာပိုဒ်၊ စတိုင်များနှင့် တည်းဖြတ်ခြင်း အုပ်စုများ ပါရှိသည်။
Dialog Box launcher
အုပ်စုတစ်ခု၏ထောင့်ရှိ မြှားငယ်။ ၎င်းသည် Ribbon တွင် အဆင်မပြေသည့်အရာများအပါအဝင် ရွေးချယ်မှုတိုင်းဖြင့် ဒိုင်ယာလော့ဂ်ဘောက်စ်အပြည့်အစုံကို ဖွင့်ပေးသည်။

နောက်ထပ် နယ်ပယ်နှစ်ခုကို သိဖို့ လိုပါတယ်။ Ribbon ၏အထက် Quick Access Toolbar တွင် သင် တစ်ချက်နှိပ်ရုံဖြင့် လိုချင်သော command များကို ကိုင်ဆောင်ထားပါသည် (Save, Undo, Redo)။ အောက်ခြေရှိ status bar သည် စာမျက်နှာနံပါတ်နှင့် စကားလုံးအရေအတွက်ကို အစီရင်ခံပြီး ဇူးမ်ဆလိုက်ကို ကိုင်ထားသည်။

ဖော်မတ်ချခြင်း အဆင့်နှစ်ဆင့်

Word သည် မတူညီသော အဆင့်နှစ်ခုတွင် ဖော်မတ်ချခြင်းကို သက်ရောက်မှုရှိသည်။ ၎င်းတို့ကို စိတ်ရှုပ်ထွေးစေခြင်းသည် "ပြုမူမည်မဟုတ်" ဖော်မတ်ပြုလုပ်ခြင်း၏ အဖြစ်အများဆုံး အကြောင်းရင်းဖြစ်သည်။

LevelApplies toExamplesGroup

ထိပ်ဖျားဝှက်ထားသော ¶ အမှတ်အသားများကို ပြသရန် Ctrl + Shift + 8 ကို နှိပ်ပါ။ စာပိုဒ်တစ်ခုစီကို ဘယ်မှာအဆုံးသတ်သည်ကိုကြည့်ခြင်းဖြင့် ဖော်မတ်ချခြင်းပြဿနာများကို အဖြေရှာရန်ပိုမိုလွယ်ကူစေသည်။

အကွာနှင့် indents

လိုင်းအကွာအဝေး သည် စာပိုဒ်တစ်ခုအတွင်းရှိ စာကြောင်းများကြား အကွာအဝေးကို ထိန်းချုပ်သည်။ ရှေ့နှင့်နောက်အကွာအဝေးသည် စာပိုဒ်များကြားကွာဟချက်ကို ထိန်းချုပ်သည်။ မျဉ်းကြောင်းနှင့် စာပိုဒ်အကွာအဝေးခလုတ်မှ သို့မဟုတ် စာပိုဒ်ဒိုင်ယာလော့ဘောက်စ်တွင် အတိအကျ သတ်မှတ်ပါ။

ဘုံအမှားစာပိုဒ်များကိုခွဲရန် Enter ကို နှစ်ကြိမ်နှိပ်ခြင်း သို့မဟုတ် space bar ကို indent သို့ ထပ်ခါထပ်ခါ နှိပ်ပါ။ စာသားကို တည်းဖြတ်ပြီးသည်နှင့် နှစ်ခုလုံးကွဲသွားပါသည်။ ၎င်းအစား Spacing After နှင့် indent ထိန်းချုပ်မှုများကို အသုံးပြုပါ။

လုပ်ဆောင်ခဲ့သည့် ဥပမာ- သတိပေးချက်ကို ဖော်မတ်လုပ်ခြင်း။

  1. ခေါင်းစဉ် Staff Training Day ကို ရိုက်ထည့်ပြီး Enter ကို နှိပ်ပါ၊ ထို့နောက် အသေးစိတ် စာကြောင်း နှစ်ကြောင်း ရိုက်ပါ။
  2. ခေါင်းစဉ်ကိုနှိပ်ပါ။ ၎င်းကို ဗဟိုပြုရန် Ctrl + E ကို နှိပ်ပါ။ ချိန်ညှိမှုသည် paragraph formatting ဖြစ်သောကြောင့်၊ ရွေးချယ်ရန်မလိုအပ်ပါ။
  3. ခေါင်းစဉ်စာသားကို ရွေးပါ၊ အရွယ်အစားကို 18 ဟု သတ်မှတ်ပြီး Ctrl + B ကို နှိပ်ပါ။
  4. စာကိုယ်စာပိုဒ်ကို နှိပ်ပါ၊ ၎င်းကို အကြောင်းပြရန် Ctrl + J ကို နှိပ်ပြီး Spacing After ကို 6 pt သို့ သတ်မှတ်ပါ။

ဖော်မတ်ထုတ်ခြင်းကို ဖယ်ရှားခြင်း။

ဖော်မတ်ဖော်မတ်မှားသွားသောအခါ ရှင်းလင်းခြင်းသည် ပြုပြင်ခြင်းထက် ပိုမြန်သည်။ Ctrl + Space သည် ရွေးချယ်မှုမှ character formatting ကို ဖယ်ရှားပြီး Ctrl + Q သည် paragraph formatting ကို ဖယ်ရှားသည်။ ဖောင့်အုပ်စုရှိ Clear All Formatting ခလုတ်သည် နှစ်ခုစလုံးကို လုပ်ဆောင်သည်။

သော့ယူမှုများ

  • Ribbon ကို တဘ်များအဖြစ် ဖွဲ့စည်းထားပြီး၊ ထို့နောက် အဖွဲ့များ၊ ထို့နောက် အမိန့်များပေးသည်။ dialog box launcher သည် ရွေးချယ်မှုတိုင်းကို ဖော်ပြသည်။
  • Character formatting သည် ရွေးချယ်မှုတစ်ခု လိုအပ်ပါသည်။ paragraph formatting စာပိုဒ်တွင် cursor သာ လိုအပ်သည်။
  • Justify သည် စာသားကို အနားသတ်နှစ်ခုလုံးသို့ ချိန်ညှိပေးသည်။ အပိုထည့်သွင်းမှု ခလုတ်များဖြင့် ဘယ်သောအခါမှ အကွာအဝေးဆက်တင်များဖြင့် ကွာဟချက်များကို ထိန်းချုပ်ပါ။

သင်၏နားလည်မှုကိုစစ်ဆေးပါ။

စာပိုဒ်တစ်ခုအတွင်းကို နှိပ်ပြီး Ctrl + B ကို နှိပ်သော်လည်း မည်သည့်အရာမှ ရဲရင့်သွားမည်မဟုတ်ပေ။ ဘာကြောင့်လဲ?

Bold သည် character formatting ဖြစ်သောကြောင့် ရွေးထားသောစာသားနှင့် သက်ဆိုင်ပါသည်။ မည်သည့်အရာကိုမျှ မရွေးချယ်ဘဲ ၎င်းသည် သင်နောက်ရိုက်မည့်အရာကိုသာ အကျိုးသက်ရောက်သည်။

ဘယ် alignment က ဘယ်ဘက်နဲ့ ညာဘက်မှာ တည့်တည့်အစွန်းကို ပေးတယ်။

Justify (Ctrl+J)။ Word သည် စာလုံးများကြားအကွာအဝေးကို ချိန်ညှိပေးသောကြောင့် မျဉ်းလုံးတစ်ခုစီသည် အနားသတ်နှစ်ခုစလုံးသို့ ရောက်သည်။

ဖောင့်အုပ်စုတွင် မမြင်နိုင်သော ရွေးစရာတစ်ခုကို မည်သည့်နေရာတွင် ရှာမည်နည်း။

ဖောင့်အပြည့်အစုံကို ဖွင့်ရန် အုပ်စု၏ထောင့်ရှိ ဒိုင်ယာလော့ဂ်ဘောက်စ် launcher ကို နှိပ်ပါ သို့မဟုတ် Ctrl + D ကိုနှိပ်ပါ။
