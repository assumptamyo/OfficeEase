သင်ခန်းစာ ၅.၁

တူညီသောစာတစ်စောင်ကို လူနှစ်ရာထံ ပေးပို့ခြင်းသည် တစ်ဦးစီ၏အမည်နှင့် လိပ်စာပါသော စာလုံးနှစ်ရာကို ရိုက်ထည့်ခြင်းဟု မဆိုလိုပါ။ Mail merge သည် စာရင်းရှိလူတိုင်းအတွက် စိတ်ကြိုက်မိတ္တူထုတ်လုပ်ရန် စာရွက်စာတမ်းတစ်ခုအား ဒေတာစာရင်းတစ်ခုနှင့် ပေါင်းစပ်ထားသည်။

သင်ယူမှုရည်ရွယ်ချက်များ

ဤသင်ခန်းစာ၏အဆုံးတွင် သင်လုပ်နိုင်သည်-

  • mail merge တစ်ခု၏ အစိတ်အပိုင်းသုံးခုကို ဖော်ပြပါ။
  • ပင်မစာရွက်စာတမ်းကို ဒေတာရင်းမြစ်တစ်ခုသို့ ချိတ်ဆက်ပြီး ပေါင်းစည်းထားသော အကွက်များကို ထည့်သွင်းပါ။
  • အစမ်းကြည့်ရှုခြင်း၊ စစ်ထုတ်ခြင်းနှင့် စာရွက်စာတမ်းများ၊ ပရင်တာ သို့မဟုတ် အီးမေးလ်သို့ ပေါင်းစည်းခြင်း အပြီးသတ်ပါ။
  • ဒေတာအလိုက် စာသားကွဲပြားရန် စည်းမျဉ်းကို အသုံးပြုပါ။

အစိတ်အပိုင်းသုံးခု

အဓိကစာရွက်စာတမ်း
လူတိုင်းအတွက် တူညီသော စာသားပါရှိသော စာ၊ အီးမေးလ်၊ အညွှန်း သို့မဟုတ် လက်မှတ်။
ဒေတာအရင်းအမြစ်
လက်ခံသူများစာရင်း- အများအားဖြင့် Excel worksheet ဖြစ်သော်လည်း Outlook အဆက်အသွယ်စာရင်း၊ Access table သို့မဟုတ် Word တွင် ရိုက်ထည့်ထားသော စာရင်းတစ်ခုဖြစ်သည်။ အတန်း တစ်ခုစီသည် လူတစ်ဦး ( မှတ်တမ်း) ဖြစ်ပြီး ကော်လံ တစ်ခုစီသည် အချက်အလက်တစ်ခု ( အကွက်) ဖြစ်သည်။
နယ်ပယ်များကို ပေါင်းစည်းပါ။
«First_Name» ကဲ့သို့သော အကွက်များကြားတွင် ပြသထားသည့် ပင်မစာရွက်စာတမ်းတွင် Placeholders။ ပေါင်းစည်းစဉ်အတွင်း တစ်ခုစီကို ထိုလူ၏တန်ဖိုးဖြင့် အစားထိုးသည်။
ထိပ်ဖျားသင်မစတင်မီ Excel စာရင်းကို သေချာပြင်ဆင်ပါ။ ကော်လံခေါင်းစီးများကို အတန်း 1 တွင်ထည့်ပါ၊ နေရာလွတ်များမပါသော နာမည်အတိုများကိုသုံးပါ (First_Name၊ Company၊ City)၊ အတန်းအလွတ်မထားခဲ့ဘဲ ကော်လံတစ်ခုလျှင် အချက်အလက်တစ်မျိုးကို သိမ်းဆည်းပါ။

mail merge အလုပ်အသွားအလာ

ညွှန်ကြားချက်များအားလုံးသည် သင်အသုံးပြုသည့်အစီအစဥ်အတိုင်း ဘယ်မှညာသို့ စီစဉ်ပေးသည့် Mailings တက်ဘ်ပေါ်တွင် ရှိနေသည်။

  1. စာရွက်စာတမ်းအမျိုးအစားကို ရွေးပါ။ Start Mail Merge > စာလုံးများ၊ အီးမေးများ၊ စာအိတ်များ၊ အညွှန်းများ သို့မဟုတ် လမ်းညွှန်များ။
  2. ဒေတာကို ချိတ်ဆက်ပါ။ Select Recipients > Use an Existing List၊ ထို့နောက် Excel ဖိုင်သို့ ကြည့်ရှုပြီး worksheet ကို ရွေးပါ။
  3. စာရင်းကို ပြန်လည်ပြင်ဆင်ပါ။ Edit Recipient List သည် သင့်အား လူတစ်ဦးချင်းစီကို ဖြုတ်ရန်၊ စာရင်းကို စီရန် သို့မဟုတ် စစ်ထုတ်နိုင်သည်၊ ဥပမာ- မြို့တစ်မြို့သို့ ပေးနိုင်သည်။
  4. အကွက်များကို ထည့်သွင်းပါ။ တန်ဖိုးတစ်ခုစီ ပိုင်ဆိုင်သည့်နေရာကို နှိပ်ပြီး Insert Merge Field မှ ရွေးချယ်ပါ။ အကွက်များကြားတွင် ကွက်လပ်နှင့် သတ်ပုံတို့ကို သင်ကိုယ်တိုင် ရိုက်ထည့်ပါ။
  5. Preview. Preview Results သည် placeholders ကို ဒေတာအစစ်အမှန်ဖြင့် အစားထိုးသည်။ မှတ်တမ်းများကိုဖြတ်ကျော်ရန် မြှားများကိုသုံး၍ အရှည်နှင့်အတိုအမည်များဖြင့် အပြင်အဆင်ကိုစစ်ဆေးပါ။
  6. Finish. Finish & Merge နှင့် အထွက်ကို ရွေးပါ။

အထွက်ကိုရွေးချယ်ခြင်း။

အပြီးသတ် & ပေါင်းစည်းခြင်း ရွေးချယ်မှုResultဘယ်အချိန်မှာသုံးပါ။
Edit Individual Documentsစာမျက်နှာတစ်ခုလျှင် တစ်ဦးစီ စိတ်ကြိုက် မိတ္တူတိုင်း ပါဝင်သည့် စာရွက်စာတမ်းအသစ်ရလဒ်များကို PDF အဖြစ် စစ်ဆေးရန်၊ ချိန်ညှိရန် သို့မဟုတ် သိမ်းဆည်းလိုပါသည်။
Print Documentsမိတ္တူများကို ပရင်တာသို့ တိုက်ရိုက်ပေးပို့သည်။အစမ်းကြည့်ရှုမှုမှန်ကန်ပြီး စာရွက်မိတ္တူများ လိုအပ်ပါသည်။
Send Email Messagesလက်ခံသူ တစ်ဦးလျှင် အီးမေးလ် တစ်စောင်၊ Outlook မှတဆင့် ပေးပို့သည်။စာရင်းတွင် အီးမေးလ်လိပ်စာကော်လံတစ်ခု ပါရှိသည်။
အရေးကြီးတယ်။ပေါင်းစည်းခြင်းဖြင့် ပေးပို့ထားသော အီးမေးလ်များကို ချက်ချင်း ပြန်လည်သိမ်းဆည်း၍ မရပါ။ စာရင်းအစစ်အမှန်ကို အီးမေးလ်မပို့မီ Edit Individual Documents သို့ အမြဲတမ်း ပေါင်းစည်းပါ သို့မဟုတ် သင်ကိုယ်တိုင် စမ်းသပ်မှုတစ်ခု ပေးပို့ပါ။

ပေါင်းစပ်နယ်ပယ်များနှင့် စည်းမျဉ်းများ

Address Block and Greeting Line assemble several fields into a correctly formatted address or salutation. If the result is wrong, use Match Fields to tell Word which of your columns holds the surname, the city and so on.

Rules စာသားကို ဒေတာပေါ် မူတည်အောင်လုပ်ပါ။ အသုံးဝင်ဆုံးမှာ If…Then…Else ဖြစ်သည်- ဥပမာ၊ Status အကွက်သည် Member နှင့် ညီမျှပါက "သင်၏ အဖွဲ့ဝင်လျှော့စျေးသည် 20%" ဟု ထည့်သွင်းပါ။ သို့မဟုတ်ပါက "လျှော့စျေးတစ်ခုရရှိရန် ယနေ့ပါဝင်ပါ" ဟု ထည့်သွင်းပါ။

လုပ်ဆောင်ခဲ့သည့် ဥပမာ- ပွဲလက်မှတ်များ

  1. လက်မှတ်ဒီဇိုင်းကိုဖွင့်ပြီး Start Mail Merge > Letters ကို ရွေးပါ။
  2. ၎င်းကို လက်ရှိစာရင်းကို အသုံးပြုပါ ဖြင့် Attendees.xlsx နှင့် ချိတ်ဆက်ပါ။
  3. အမည်လိုင်းကို နှိပ်ပြီး ၎င်းတို့ကြားတွင် နေရာလွတ်တစ်ခုပါရှိသော «First_Name» နှင့် «Last_Name» အကွက်များကို ထည့်သွင်းပါ။ အောက်ဖော်ပြပါစာကြောင်းတွင် "သင်တန်း" ကိုထည့်သွင်းပါ။
  4. ရလဒ်များကို အစမ်းကြည့်ရှုပြီး ရှည်လျားသောအမည်များနှင့် ကိုက်ညီမှုရှိမရှိ စစ်ဆေးရန် မှတ်တမ်းများစွာကို ဖြတ်ကျော်ပါ။
  5. Finish & Merge > Edit Individual Documents ကို ရွေးပါ၊ ထို့နောက် ရလဒ်ကို PDF အဖြစ် သိမ်းဆည်းပါ။

သော့ယူမှုများ

  • mail merge သည် အကွက်များကို ပေါင်းစည်းခြင်းဖြင့် ပင်မစာရွက်စာတမ်းတစ်ခုသို့ ဒေတာအရင်းအမြစ်တစ်ခုသို့ ချိတ်ဆက်သည်။
  • ဒေတာရင်းမြစ်တွင် အတန်းများသည် မှတ်တမ်းများဖြစ်ပြီး ကော်လံများသည် အကွက်များဖြစ်သည်။
  • Mailings တက်ဘ်ကို အလုပ်အသွားအလာ၏ အစီအစဥ်အတိုင်း ဖော်ပြထားသည်- စတင်ရန်၊ ရွေးချယ်ရန်၊ ထည့်သွင်းရန်၊ အကြိုကြည့်ရှုရန်၊ အပြီးသတ်ပါ။
  • ပုံနှိပ်ခြင်း သို့မဟုတ် အီးမေးလ်မပို့မီ အမြဲကြိုတင်ကြည့်ရှုပြီး စာရွက်စာတမ်းတစ်ခုသို့ ပေါင်းစည်းပါ။

သင်၏နားလည်မှုကိုစစ်ဆေးပါ။

လက်ခံသူစာရင်း Excel တွင် အတန်းတစ်ခုသည် အဘယ်အရာကိုကိုယ်စားပြုသနည်း၊ ကော်လံတစ်ခုသည် အဘယ်အရာကိုကိုယ်စားပြုသနည်း။

အတန်းတစ်ခုသည် မှတ်တမ်းတစ်ခုဖြစ်ပြီး လက်ခံသူတစ်ဦးဖြစ်သည်။ ကော်လံတစ်ခုသည် ပထမအမည် သို့မဟုတ် မြို့ကဲ့သို့ အကွက်တစ်ခုဖြစ်သည်။

သင်၏ ပေါင်းစပ်ထားသော စာလုံးများသည် နာမည်အစစ်များအစား "Dear «First_Name»" ကို ပြသသည်။ ဘယ်အဆင့်ကို လွတ်သွားတာလဲ။

ပေါင်းစည်းမှု မပြီးမြောက်ခဲ့ပါ။ ဒေတာကိုစစ်ဆေးရန် အကြိုကြည့်ရှုမှုရလဒ်များကို သုံးပါ၊ ထို့နောက် စိတ်ကြိုက်မိတ္တူများကို ထုတ်လုပ်ရန် အပြီးသတ် & ပေါင်းစည်းပါ။

ပထမဆုံးကြိုးစားမှုအတွက် ဘယ် Finish & Merge ရွေးချယ်မှုက ဘေးအကင်းဆုံးဖြစ်ပြီး ဘာကြောင့်လဲ။

တစ်ဦးချင်းစီ စာရွက်စာတမ်းများကို တည်းဖြတ်ပါ၊ အဘယ်ကြောင့်ဆိုသော် ၎င်းသည် မည်သည့်အရာကိုမျှ ပုံနှိပ်ခြင်း သို့မဟုတ် မပေးပို့မီ သင်စစ်ဆေးပြီး ပြင်နိုင်သည့် စာရွက်စာတမ်းကို ထုတ်လုပ်ပေးသောကြောင့် ဖြစ်သည်။
