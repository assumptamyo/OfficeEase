သင်ခန်းစာ ၁.၂

ပရော်ဖက်ရှင်နယ် စာရွက်စာတမ်းများကို အစမှ အဆုံးထိ ရိုက်ခဲပါသည်။ ၎င်းတို့ကို ရှိပြီးသား ပစ္စည်းမှ ပေါင်းစပ်ထားသည်။ ဤသင်ခန်းစာတွင် အကြောင်းအရာကို ထိရောက်စွာ ရွှေ့ပြောင်းခြင်းနှင့် ဖော်မတ်ချခြင်းဆိုင်ရာ ကိရိယာများကို အကျုံးဝင်သည်- Clipboard၊ Paste Special၊ Format Painter နှင့် အနုစိတ်ထိန်းချုပ်မှုများ။

သင်ယူမှုရည်ရွယ်ချက်များ

ဤသင်ခန်းစာ၏အဆုံးတွင် သင်လုပ်နိုင်သည်-

  • ပေးထားသည့် အခြေအနေအတွက် မှန်ကန်သော paste ရွေးချယ်မှုကို ရွေးချယ်ပါ။
  • အရာများစွာကို စုဆောင်းပြီး ကူးထည့်ရန် Office Clipboard ကို အသုံးပြုပါ။
  • Format Painter ဖြင့် စာသားတစ်ပိုင်းမှ နောက်တစ်ခုသို့ ဖော်မတ်ကူးယူပါ။
  • စာပိုဒ်တစ်ပိုဒ်အတွက် indents၊ တက်ဘ် ရပ်တန့်ခြင်းနှင့် စာမျက်နှာခွဲခြင်း ရွေးစရာများကို သတ်မှတ်ပါ။

ဖြတ်၊ ကူးထည့်ပါ။

အခြေခံ အမိန့်သုံးခုမှာ Ctrl + X (ဖြတ်), Ctrl + C (မိတ္တူ) နှင့် Ctrl + V (ကူးထည့်သည်)။ အရေးကြီးတာက ဘယ်လို အကြောင်းအရာတွေ ရောက်လာတာလဲ။ ကူးထည့်လိုက်တိုင်း Word ပြီးနောက် သေးငယ်သော Paste Options ခလုတ်ကို ပြသည်; ထိုနေရာတွင် သင်ပြုလုပ်သောရွေးချယ်မှုသည် စာသားသည် ၎င်း၏အသွင်အပြင်ဟောင်းကို ထိန်းသိမ်းထားခြင်းရှိ၊ သို့မဟုတ် အသစ်ကို လက်ခံမည်ဆိုသည်ကို ဆုံးဖြတ်သည်။

ကူးထည့်ပါ။အဲဒါက ဘာလဲ။ဘယ်အချိန်မှာ သုံးမလဲ။
Keep Source Formattingမူရင်းဖောင့်၊ အရောင်နှင့် အပြင်အဆင်ကို ထိန်းသိမ်းထားသည်။ကူးထည့်ထားသည့်အရာသည် ကိုးကားထားသောဇယားကဲ့သို့ အတိအကျမြင်ရပါမည်။
Merge Formattingပတ်ဝန်းကျင်ပုံစံကို လက်ခံသော်လည်း ရဲရင့်ပြီး စာလုံးစောင်းထားပါ။အလေးပေးထိန်းသိမ်းထားစဉ်တွင် စာသားကို အစီရင်ခံစာတစ်ခုအဖြစ် ထည့်သွင်းခြင်း။
Keep Text Onlyဖော်မတ်ချခြင်းအားလုံးကို ဖယ်ရှားပြီး ရိုးရိုးစာသားကို ကူးထည့်ပါ။ဝဘ်စာမျက်နှာများ၊ အီးမေးလ်များ သို့မဟုတ် PDF များမှ ကူးယူခြင်း။
ထိပ်ဖျားဝဘ်ဆိုက်တစ်ခုမှ ကူးယူထားသော စာသားများသည် များသောအားဖြင့် ၎င်းနှင့် ဝှက်ထားသော ဖောင့်များ၊ အရောင်များနှင့် အကွာအဝေးများကို ယူဆောင်လာကြသည်။ ၎င်းကို Keep Text Only အဖြစ် ကူးထည့်ကာ သင်ကိုယ်တိုင် ဖော်မတ်လုပ်ပါ။ စာရွက်စာတမ်းသည် တသမတ်တည်းရှိနေပါသည်။

Paste Special

Paste Special dialog box ကိုဖွင့်ရန် Ctrl + Alt + V ကိုနှိပ်ပါ။ ၎င်းသည် ကူးယူထားသော အကြောင်းအရာကို ကူးထည့်နိုင်သည့် ဖော်မတ်တိုင်းကို စာရင်းပြုစုသည်- ဖော်မတ်လုပ်ထားသော စာသား၊ ပုံစံမချသော စာသား၊ ရုပ်ပုံ သို့မဟုတ် လင့်ခ်ချိတ်ထားသော အရာဝတ္ထုတစ်ခုတို့ကို ဖော်ပြသည်။ ဥပမာ၊ Excel အပိုင်းအခြားတစ်ခုအတွက် လင့်ခ်ကို ကူးထည့်ပါကို ရွေးခြင်းဖြင့်၊ ဥပမာ၊ ဇယားသည် Word ကို workbook နှင့် ချိတ်ဆက်ထားသောကြောင့် ကိန်းဂဏန်းများပြောင်းလဲသည့်အခါ အပ်ဒိတ်လုပ်ထားသည်။

Office Clipboard

သာမန်ကလစ်ဘုတ်သည် ကူးယူထားသော နောက်ဆုံးအရာကိုသာ မှတ်မိသည်။ Office Clipboard သည် 24 ခု အထိ သိမ်းဆည်းထားသည်။ Clipboard အုပ်စုရှိ dialog box launcher ဖြင့် ၎င်းကိုဖွင့်ပါ။ သင်ကူးယူထားသော အရာတစ်ခုစီကို အကန့်တွင် ထည့်ထားပြီး ၎င်းကို ကူးထည့်ရန် မည်သည့်အရာကိုမဆို နှိပ်နိုင်သည် သို့မဟုတ် Paste All ကို ရွေးချယ်နိုင်သည်။

ရှည်လျားသော အရင်းအမြစ်စာရွက်စာတမ်းမှ ကောက်နှုတ်ချက်များစွာကို စုဆောင်းသည့်အခါ ၎င်းသည် မှန်ကန်သောကိရိယာဖြစ်သည်- ၎င်းတို့အားလုံးကို လက်မှတ်တစ်ခုတွင် ကူးယူပြီး ၎င်းတို့ပိုင်ဆိုင်သည့်နေရာတွင် ကူးထည့်ပါ။

Format Painter

Format Painter မိတ္တူ ဖော်မတ်ခြင်း၊ စာသားမဟုတ်ဘဲ။ ခေါင်းစဉ်တစ်ခုသည် အခြားတစ်ခုနှင့်တူအောင် ပြုလုပ်ရန် အမြန်ဆုံးနည်းလမ်းဖြစ်သည်။

  1. သင်ကူးယူလိုသော ဖော်မတ်ချထားသည့် စာသားကို နှိပ်ပါ သို့မဟုတ် ရွေးပါ။
  2. Clipboard အဖွဲ့ရှိ Format Painter ကို နှိပ်ပါ။ ညွှန်တံသည် ဆေးစုတ်တံဖြစ်လာသည်။
  3. ဖော်မတ်ချခြင်းကို လက်ခံသင့်သည့် စာသားတစ်ဖက်ကို ဆွဲယူပါ။

ကလစ်တစ်ချက်နှိပ်ရုံဖြင့် တစ်ကြိမ်လုပ်ဆောင်သည်။ Double-click သော့ခတ်ရန် Format Painter သည် စာသားအပိုင်းအစများစွာကို ဆက်တိုက်ခြယ်မှုန်းနိုင်သည်။ ပြီးသောအခါ Esc ကိုနှိပ်ပါ။ ဖော်မတ်ချခြင်းအား ကူးယူရန် ကီးဘုတ်နှင့်ညီမျှသော Ctrl + Shift + C နှင့် ၎င်းကို အသုံးပြုရန် Ctrl + Shift + V ။

အဆင့်မြင့်စာပိုဒ်ရွေးချယ်မှုများ

စာပိုဒ်အုပ်စုရှိ ဒိုင်ယာလော့ဂ်ဘောက်စ် launcher သည် အပြင်အဆင်အပေါ် တိကျသောထိန်းချုပ်မှုပေးသည့် ဆက်တင်များကိုဖွင့်သည်။

ပထမစာကြောင်း indent
စာပိုဒ်၏ပထမစာကြောင်းကို ဝတ္ထုတစ်ပုဒ်ကဲ့သို့ ညာဘက်သို့ရွှေ့ပါ။
တွဲလောင်း indent
ပထမလိုင်းကို ချန်ထားပြီး ကျန် indents။ ၎င်းသည် ကိုးကားစာရင်းများအတွက် စံပုံစံဖြစ်သည်။
တဘ်ရပ်သည်။
သင် Tab ကိုနှိပ်သောအခါ စာသားပြောင်းသွားသည့် အနေအထားများကို ပုံသေသတ်မှတ်ထားသည်။ ၎င်းတို့သည် စာသားကော်လံများကို စိတ်ချယုံကြည်စွာ ညှိပေးသည်။ space bar မပါဘူး။
နောက်တစ်ခုနဲ့ ဆက်ထားပါ။
ဤစာပိုဒ်နှင့်အောက်ပါစာပိုဒ်ကြားတွင် စာမျက်နှာကွဲခြင်းကို တားဆီးသည်၊ ထို့ကြောင့် စာမျက်နှာတစ်ခု၏အောက်ခြေတွင် ခေါင်းစဉ်တစ်ခုသည် ဘယ်သောအခါမှ မထိုင်ပါ။
မုဆိုးမ/မိဘမဲ့ ထိန်းချုပ်မှု
စာပိုဒ်တစ်ကြောင်း၏ စာမျက်နှာတစ်ခု၏ အပေါ် သို့မဟုတ် အောက်ခြေတွင် သောင်တင်နေခြင်းကို ရပ်ပါ။
ဘုံအမှားStyle တွင် Format Painter ကို အသုံးပြုခြင်းက ပိုကောင်းပါသည်။ Format Painter သည် တစ်ကြိမ် ဖော်မတ်ချခြင်း မိတ္တူ; နောက်ပိုင်း မင်းစိတ်ပြောင်းရင် အပိုင်းတိုင်းကို ပြန်ဆေးရမယ်။ Module 4 တွင်ပါရှိသော စတိုင်များကို နေရာတိုင်းတွင် တစ်ပြိုင်နက် အပ်ဒိတ်လုပ်ပါ။

လုပ်ဆောင်ခဲ့သည့် ဥပမာ- အကျဉ်းချုပ်မှတ်စုကို စုစည်းခြင်း။

  1. Office Clipboard ကိုဖွင့်ပါ၊ ထို့နောက် မတူညီသော အရင်းအမြစ်စာရွက်စာတမ်းများမှ စာပိုဒ်သုံးခုကို ကူးယူပါ။
  2. စာရွက်စာတမ်းအသစ်တွင်၊ တစ်ခုစီကိုကူးထည့်ကာ သုံးခုစလုံးကိုက်ညီစေရန် Keep Text Only ကိုရွေးချယ်ပါ။
  3. ပထမခေါင်းစဉ်ခွဲကို ရဲရင့်၊ 14 pt၊ နက်ပြာရောင်အဖြစ် ပုံစံဖော်ပါ။
  4. ထိုခေါင်းစဉ်ခွဲရှိ cursor ဖြင့်၊ Format Painter ကို နှစ်ချက်နှိပ်ပါ၊ ကျန်ခေါင်းစဉ်ခွဲတစ်ခုစီကို နှိပ်ပါ၊ ထို့နောက် Esc ကိုနှိပ်ပါ။

သော့ယူမှုများ

  • Ctrl + Alt + V ဖွင့်သည် Paste Special; Keep Text Only သည် ပြင်ပအကြောင်းအရာအတွက် အလုံခြုံဆုံးရွေးချယ်မှုဖြစ်သည်။
  • Office Clipboard တွင် ပစ္စည်း 24 ခုအထိရှိသည်။
  • Format Painter ကို နှစ်ချက်နှိပ်ခြင်းဖြင့် ထပ်ခါတလဲလဲ အသုံးပြုရန်အတွက် လော့ခ်ကျစေပါသည်။ Esc က ၎င်းကို ပိတ်ထားသည်။
  • Indents၊ တက်ဘ် ရပ်တန့်ခြင်း နှင့် စာမျက်နှာခွဲခြင်း ရွေးချယ်စရာများ သည် လူကိုယ်တိုင် အကွာအဝေး နှင့် လူကိုယ်တိုင် စာမျက်နှာခွဲခြင်းများကို အစားထိုးသည်။

သင်၏နားလည်မှုကိုစစ်ဆေးပါ။

သင်သည် ဝဘ်စာမျက်နှာမှ စာပိုဒ်တစ်ခုကို ကူးထည့်လိုက်သည်နှင့် ၎င်းသည် ထူးဆန်းသောအကွာအဝေးရှိသည့် မီးခိုးရောင်ဖောင့်တစ်ခုသို့ ရောက်ရှိသွားသည်။ ဘာကိုရွေးသင့်လဲ။

Keep Text Only သည် ဝဘ်ဖော်မတ်ချခြင်းကို ဖယ်ရှားပေးသောကြောင့် စာသားသည် သင့်စာရွက်စာတမ်း၏ ဖော်မတ်ပြုလုပ်ခြင်းတွင် ကြာပါသည်။
