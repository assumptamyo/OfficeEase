သင်ခန်းစာ ၃.၂

Layout တဘ် သည် ရုပ်ပိုင်းဆိုင်ရာ စာမျက်နှာကို သတ်မှတ်သည်- ၎င်း၏ အရွယ်အစား၊ ၎င်း၏အနားသတ်များနှင့် စာသားများကို မည်ကဲ့သို့ ပိုင်းခြားထားသည်။ ဤသင်ခန်းစာ၏ဗဟိုသဘောတရားမှာ ကဏ္ဍဖြစ်ပြီး၊ စာရွက်စာတမ်းတစ်ခုတွင် မတူညီသောအပြင်အဆင်များဖြင့် စာမျက်နှာများပါ၀င်စေမည့် ယန္တရားဖြစ်သည်။

သင်ယူမှုရည်ရွယ်ချက်များ

ဤသင်ခန်းစာ၏အဆုံးတွင် သင်လုပ်နိုင်သည်-

  • ချည်နှောင်မှုအတွက် gutter အပါအဝင် အနားသတ်များ၊ တိမ်းညွှတ်မှုနှင့် စာရွက်အရွယ်အစားကို သတ်မှတ်ပါ။
  • အပိုင်းခွဲတစ်ခုမှ စာမျက်နှာခွဲခြင်းကို ခွဲခြားပြီး မှန်ကန်သောအမျိုးအစားကို ရွေးချယ်ပါ။
  • စာမျက်နှာတစ်မျက်နှာကို အခြားစာရွက်စာတမ်းနှင့် ကွဲပြားသော လမ်းကြောင်းကို ပေးပါ။
  • ကော်လံများတွင် စာသားကိုစီစဉ်ပြီး ကော်လံတစ်ခုအဆုံးသတ်မည့်နေရာကို ထိန်းချုပ်ပါ။

စာမျက်နှာ စနစ်ထည့်သွင်းခြင်း။

Page Setup အဖွဲ့သည် စာမျက်နှာတစ်ခုကို သတ်မှတ်သည့် ဆက်တင်သုံးခုကို ကိုင်ဆောင်ထားသည်။

SettingOptionsNotes

gutter အနားသတ် သည် စာမျက်နှာ၏ ချိတ်ဆွဲထားသော အစွန်းသို့ အပိုနေရာများ ထည့်ထားသည်။ အစီရင်ခံစာကို ဘယ်ဘက်တွင် လိမ်ချည်နှောင်ထားမည် သို့မဟုတ် ချည်နှောင်မည်ဆိုပါက၊ 0.5 လက်မခန့်ရှိသော gutter သည် စာသားကို ဖုံးအုပ်ခြင်းမှ စည်းနှောင်ခြင်းကို ရပ်တန့်စေသည်။ ၎င်းကို Margins > Custom Margins အောက်တွင် သတ်မှတ်ပါ။

စာမျက်နှာခွဲခြင်းနှင့် အပိုင်းခွဲခြင်းများ

နှစ်ခုစလုံးကို Layout > Breaks မှ ထည့်သွင်းထားပြီး ၎င်းတို့သည် ဖန်သားပြင်ပေါ်တွင် ပုံသဏ္ဍန်တူသော်လည်း ၎င်းတို့သည် အလွန်ကွဲပြားသော အလုပ်များကို လုပ်ဆောင်ပါသည်။

စာမျက်နှာကွဲ
အောက်ပါစာသားကို နောက်စာမျက်နှာ၏ထိပ်သို့ တွန်းပါ။ စာမျက်နှာဆက်တင်များသည် အတိအကျတူညီနေပါသည်။ ဖြတ်လမ်းလင့်ခ်- Ctrl + Enter။
ပုဒ်မချိုး
စာရွက်စာတမ်းအား သီးခြား ကဏ္ဍများ ခွဲထားသည်။ ကဏ္ဍတစ်ခုစီတွင် ၎င်း၏ကိုယ်ပိုင်အနားသတ်များ၊ လမ်းညွှန်ချက်၊ ကော်လံများ၊ ခေါင်းစီးများ၊ အောက်ခံများနှင့် စာမျက်နှာနံပါတ်များ ပါရှိနိုင်ပါသည်။
အပိုင်းခွဲ အမျိုးအစားကဏ္ဍသစ် စတင်မည့်နေရာရိုးရိုးသုံးတယ်။
Next Pageအောက်ပါစာမျက်နှာတွင်အခင်းအကျင်း စာမျက်နှာ သို့မဟုတ် ၎င်း၏ကိုယ်ပိုင် ခေါင်းစီးပါသော အခန်းအသစ်
Continuousတူညီတဲ့စာမျက်နှာပေါ်မှာစာမျက်နှာတစ်မျက်နှာအောက်သို့ ကော်လံအရေအတွက်ကို ပြောင်းလဲခြင်း။
နောက်တစ်ခုက Page / Odd Pageနောက်စာမျက်နှာတွင်၊ညာဘက်စာမျက်နှာတွင် အမြဲတမ်းဖွင့်ထားသည့် အခန်းများ
ဘုံအမှားဦးတည်ချက်ပြောင်းခြင်းနှင့် တစ်ခုလုံး စာရွက်စာတမ်းသည် အခင်းအကျင်းပြောင်းသွားကြောင်း တွေ့ရှိခြင်း။ Orientation သည် အပိုင်းတစ်ခုအတွက် အကျုံးဝင်ပြီး အပိုင်းခွဲခြင်းမရှိသော စာရွက်စာတမ်းသည် အပိုင်းတစ်ခုတည်းဖြစ်သည်။ အခွဲများကို ဦးစွာထည့်ပါ၊ ထို့နောက် လမ်းကြောင်းပြောင်းပါ။

စာရွက်စာတမ်းတစ်ခုတွင် မတူညီသော အပြင်အဆင်များ

ပုံတူအစီရင်ခံစာ၏အလယ်တွင် စာမျက်နှာအခင်းအကျင်းတစ်ခုကို လှည့်ရန်၊ ၎င်းကို ၎င်း၏ကိုယ်ပိုင်အပိုင်းတွင် ခွဲထုတ်ပါ-

  1. ပြောင်းလဲပြီး Breaks > Next Page ထည့်သွင်းသင့်သော စာမျက်နှာ၏အဆုံးတွင် နှိပ်ပါ။
  2. အခင်းအကျင်းဖြစ်သင့်သော စာမျက်နှာ၏အဆုံးတွင် ကလစ်နှိပ်ပြီး နောက်ထပ် Next Page အပိုင်းကို ထည့်ပါ။
  3. အလယ်အပိုင်းရှိ ဘယ်ကိုမဆို နှိပ်ပြီး Orientation > Landscape ကို ရွေးပါ။

တူညီသောနိယာမသည် အခန်းတိုင်းကို ၎င်း၏ခေါင်းစီးကိုပေးသည်။ ကဏ္ဍသစ်၏ ခေါင်းစီးကိုဖွင့်ပြီး ခေါင်းစီးနှင့်အောက်ခြေတဘ်ရှိ Link to Previous ကို ပိတ်ပါ။ မဟုတ်ပါက အပိုင်းသည် ၎င်းရှေ့မှ ခေါင်းစီးကို ထပ်ခါတလဲလဲ လုပ်သည်။

ထိပ်ဖျားကွဲနေသည့်နေရာကိုကြည့်ရန် Ctrl + Shift + 8 နှင့် ¶ အမှတ်အသားများကို ဖွင့်ပါ။ အပိုင်းခွဲသည် အထက် စာသား၏ အပြင်အဆင်ကို သိမ်းဆည်းထားသောကြောင့် စာသားတစ်ခုကို ဖျက်လိုက်ခြင်းဖြင့် အောက်ပါ ကဏ္ဍ၏ အပြင်အဆင်ကို ပြောင်းလဲစေသည်။

ကော်လံများ

သတင်းလွှာများနှင့် ဘရိုရှာများသည် စာတိုတိုများကို ဖတ်ရလွယ်ကူသောကြောင့် ကော်လံများကို အသုံးပြုပါသည်။ Layout > Columns ကို ရွေးပြီး တစ်၊ နှစ်၊ သုံး၊ ဘယ် သို့မဟုတ် ညာဘက်ကို ရွေးပါ။ More Columns သည် သင့်အား အတိအကျ အကျယ်နှင့် အကွာအဝေးကို သတ်မှတ်နိုင်စေပြီး ကော်လံများကြားတွင် မျဉ်းကြောင်းကို ပေါင်းထည့်နိုင်သည်။

စာသားသည် နောက်တစ်ခုသို့ မစီးဆင်းမီ ပထမကော်လံကို ဖြည့်ပေးသည်။ ကော်လံတစ်ခုကို စောစောအဆုံးသတ်ရန်၊ Ctrl + Shift + Enter ဖြင့် ကော်လံကွဲ ကို ထည့်ပါ။

ကော်လံနှစ်ခုပါ ဆောင်းပါးတစ်ခုအပေါ်တွင် အကျယ်အဝန်းအပြည့်ရှိသော ခေါင်းစီးတစ်ခုကို ထားရှိရန်၊ ခေါင်းစီးပြီးနောက် Continuous အပိုင်းကို ပိုင်းခြားကာ ၎င်း၏အောက်ရှိ ကဏ္ဍတွင်သာ ကော်လံနှစ်ခုကို ထည့်သွင်းပါ။

လုပ်ဆောင်ခဲ့သည့် ဥပမာ- စာမျက်နှာသုံးမျက်နှာရှိသော သတင်းလွှာ

  1. အနားသတ်များကို Moderate နှင့် စာရွက်အရွယ်အစားကို A4 သို့ သတ်မှတ်ပါ။
  2. မျက်နှာဖုံးစာမျက်နှာပြီးနောက်၊ Next Page အပိုင်းခွဲတစ်ခုထည့်ပါ။ ဇယားစာမျက်နှာပြီးနောက်၊ နောက်တစ်ခုထည့်ပါ။
  3. ဇယားအပိုင်းကို နှိပ်ပြီး လမ်းကြောင်းကို Landscape အဖြစ် သတ်မှတ်ပါ။
  4. နောက်ဆုံးအပိုင်းတွင်၊ ခေါင်းစီးကိုရိုက်ထည့်ပါ၊ Continuous အကန့်ကိုထည့်ပါ၊ ထို့နောက် မျဉ်းကြောင်းတစ်ခုနှင့် ကော်လံနှစ်ခုကို အသုံးပြုပါ။

သော့ယူမှုများ

  • စာမျက်နှာခွဲခြင်းသည် စာမျက်နှာအသစ်ကို စတင်သည်။ အပိုင်းခွဲတစ်ခုသည် အပြင်အဆင်စည်းမျဉ်းအသစ်တစ်ခုကို စတင်သည်။
  • ဦးတည်ချက်၊ အနားသတ်များ၊ ကော်လံများ၊ ခေါင်းစီးများနှင့် နံပါတ်စဉ်များသည် ကဏ္ဍတစ်ခု၏ ဂုဏ်သတ္တိများဖြစ်သည်။
  • စာမျက်နှာတစ်ခုကို ခွဲထုတ်ရန် စာမျက်နှာတစ်ခုကို ခွဲထုတ်ရန်နှင့် စာမျက်နှာတစ်ခုတည်းရှိ ကော်လံများကို ပြောင်းလဲရန် ဆက်တိုက်ချိုးဖျက်မှုကို အသုံးပြုပါ။
  • gutter အနားသတ်သည် စည်းနှောင်ရန်အတွက် နေရာလွတ်ရှိသည်။

သင်၏နားလည်မှုကိုစစ်ဆေးပါ။

Ctrl + Enter နှိပ်ခြင်းနှင့် Next Page အပိုင်းခွဲတစ်ခု ထည့်သွင်းခြင်းကြား ကွာခြားချက်မှာ အဘယ်နည်း။

နှစ်ခုလုံးသည် စာသားကို စာမျက်နှာအသစ်သို့ ရွှေ့သော်လည်း အပိုင်းခွဲမှသာလျှင် ၎င်းရှေ့ရှိ စာမျက်နှာများနှင့် အနားသတ်များ၊ လမ်းညွှန်မှု၊ ကော်လံများနှင့် ခေါင်းစီးများ ကွဲပြားနိုင်သည့် ကဏ္ဍအသစ်တစ်ခုကို ဖန်တီးပေးပါသည်။

စာမျက်နှာတစ်ခုမှ ကော်လံတစ်ခုမှ စာမျက်နှာတစ်ဝက်သို့ နှစ်ကြောင်းသို့ ပြောင်းနိုင်စေမည့် မည်သည့်အကန့်သည် သင့်အား ခွင့်ပြုနိုင်သနည်း။

အပိုင်းအသစ်သည် စာမျက်နှာတစ်ခုတည်းတွင် စတင်သောကြောင့် ဆက်တိုက် အပိုင်းကွဲခြင်း။

အစီရင်ခံစာကို ဘယ်ဘက်တွင် ခရုပတ်ချည်ထားပါမည်။ မည်သည့်ဆက်တင်က စာသားကို ချိတ်တွယ်ခြင်းမှ ကာကွယ်ပေးသနည်း။

ဘယ်ဘက်ရှိ gutter အနားသတ်၊ စိတ်ကြိုက်အနားသတ်များတွင် သတ်မှတ်ထားသည်။
