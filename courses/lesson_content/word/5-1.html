Lesson 5.1

Sending the same letter to two hundred people, each with their own name and address, should not mean typing two hundred letters. Mail merge combines one document with a list of data to produce a personalised copy for every person on the list.

Learning objectives

By the end of this lesson you will be able to:

  • describe the three components of a mail merge;
  • connect a main document to a data source and insert merge fields;
  • preview, filter and complete a merge to documents, a printer or email;
  • use a rule to vary the text according to the data.

The three components

Main document
The letter, email, label or certificate containing the text that is the same for everyone.
Data source
The list of recipients: usually an Excel worksheet, but also an Outlook contact list, an Access table or a list typed in Word. Each row is one person (a record) and each column is one piece of information (a field).
Merge fields
Placeholders in the main document, shown between chevrons such as «First_Name». During the merge each one is replaced by that person's value.
TipPrepare the Excel list carefully before you start. Put the column headings in row 1, use short names without spaces (First_Name, Company, City), leave no blank rows, and keep one kind of information per column.

The mail merge workflow

All the commands are on the Mailings tab, arranged from left to right in the order you use them.

  1. Choose the document type. Start Mail Merge > Letters, E-mail Messages, Envelopes, Labels or Directory.
  2. Connect the data. Select Recipients > Use an Existing List, then browse to the Excel file and choose the worksheet.
  3. Refine the list. Edit Recipient List lets you untick individuals, sort the list, or filter it, for example to one city.
  4. Insert the fields. Click where each value belongs and choose it from Insert Merge Field. Type spaces and punctuation between fields yourself.
  5. Preview. Preview Results replaces the placeholders with real data. Use the arrows to step through the records and check the layout with long and short names.
  6. Finish. Finish & Merge and choose the output.

Choosing the output

Finish & Merge optionResultUse it when
Edit Individual DocumentsA new document containing every personalised copy, one per pageYou want to check, adjust or save the results as a PDF
Print DocumentsThe copies are sent directly to the printerThe preview is correct and paper copies are needed
Send Email MessagesOne email per recipient, sent through OutlookThe list contains an email address column
ImportantEmails sent by a merge leave immediately and cannot be recalled. Always merge to Edit Individual Documents first, or send a test to yourself, before emailing a real list.

Composite fields and rules

Address Block and Greeting Line assemble several fields into a correctly formatted address or salutation. If the result is wrong, use Match Fields to tell Word which of your columns holds the surname, the city and so on.

Rules make the text depend on the data. The most useful is If…Then…Else: for instance, if the Status field equals Member, insert "Your member discount is 20%"; otherwise insert "Join today to receive a discount".

Worked example: event certificates

  1. Open the certificate design and choose Start Mail Merge > Letters.
  2. Connect it to Attendees.xlsx with Use an Existing List.
  3. Click on the name line and insert the «First_Name» and «Last_Name» fields with a space between them; insert «Course» on the line below.
  4. Preview the results and step through several records to check that long names fit.
  5. Choose Finish & Merge > Edit Individual Documents, then save the result as a PDF.

Key takeaways

  • A mail merge joins a main document to a data source by means of merge fields.
  • In the data source, rows are records and columns are fields.
  • The Mailings tab is laid out in the order of the workflow: start, select, insert, preview, finish.
  • Always preview, and merge to a document before printing or emailing.

Check your understanding

In an Excel recipient list, what does one row represent, and what does one column represent?

A row is one record, that is one recipient. A column is one field, such as the first name or the city.

Your merged letters show "Dear «First_Name»" instead of real names. Which step was missed?

The merge was not completed. Use Preview Results to check the data, then Finish & Merge to produce the personalised copies.

Which Finish & Merge option is safest for a first attempt, and why?

Edit Individual Documents, because it produces a document you can inspect and correct before anything is printed or sent.
