Lesson 4.1

Styles mark the point at which a Word user becomes a professional one. A style does more than make text look a certain way: it tells Word what the text is. Once Word knows which paragraphs are headings, it can build navigation, tables of contents and accessible documents for you.

Learning objectives

By the end of this lesson you will be able to:

  • explain the difference between direct formatting and style-based formatting;
  • structure a document with the built-in heading styles;
  • modify an existing style and create a new one;
  • use the Navigation Pane to move through and reorganise a long document.

What a style is

A style is a named collection of formatting settings (font, size, colour, spacing, indents) that is applied in a single click from Home > Styles.

Direct formattingStyle-based formatting
How it is appliedEach property set by hand on each headingOne click applies every property
ConsistencyDepends on your memoryGuaranteed; all headings share one definition
Changing your mindEvery heading must be reformattedModify the style once; all headings update
StructureWord sees only large bold textWord recognises a heading and its level

The heading hierarchy

The built-in heading styles form an outline, exactly like the numbered sections of a textbook.

Title
The name of the document. Used once.
Heading 1
Main sections or chapters. Shortcut: Ctrl + Alt + 1.
Heading 2
Sub-sections within a Heading 1. Shortcut: Ctrl + Alt + 2.
Heading 3
Divisions of a sub-section. Shortcut: Ctrl + Alt + 3.
Normal
Body text. Shortcut: Ctrl + Shift + N.
ImportantDo not skip levels. A Heading 3 should always sit beneath a Heading 2. Choose a heading level for what the text is, never for how large you want it to look; if the size is wrong, modify the style.

What styles make possible

  • Automatic table of contents. Word builds it from the heading styles (next lesson).
  • Navigation Pane. Every heading becomes a clickable entry in an outline of the document.
  • Accessibility. Screen readers use heading levels to let visually impaired readers jump between sections.
  • Consistency and speed. A two-hundred-page document can be restyled in seconds.
  • Reliable PDF bookmarks. Headings become bookmarks when the document is exported.

Modifying and creating styles

There are two ways to change what a style looks like.

  1. Modify the definition. Right-click the style in the gallery and choose Modify. Set the font, size, colour and, through the Format button, the paragraph spacing. Click OK and every paragraph using the style changes.
  2. Update from an example. Format one heading by hand until it looks right, then right-click the style and choose Update Heading 1 to Match Selection.

To create your own style, format a paragraph, open the Styles gallery and choose Create a Style, then give it a meaningful name such as Case Study or Figure Caption. Press Alt + Ctrl + Shift + S to open the full Styles pane, which lists every style in the document.

TipIn the Modify Style dialog box, the option New documents based on this template saves your changes for future documents, so your house style is ready every time.

The Navigation Pane

Open it with View > Navigation Pane or Ctrl + F, and select the Headings tab. It shows the outline of the document. Click a heading to jump to it; drag a heading up or down to move that entire section, with all its sub-sections and text, to a new position.

Worked example: structuring an academic paper

  1. Apply Heading 1 to Introduction, Method, Results, Discussion and Conclusion.
  2. Apply Heading 2 to the sub-sections inside each.
  3. Right-click Heading 1, choose Modify, and set Arial, 18 pt, bold, with 12 pt before and 6 pt after.
  4. Open the Navigation Pane and confirm that the outline is complete and correctly nested.

Key takeaways

  • A style is a named set of formatting that also gives text a structural role.
  • Heading 1, 2 and 3 form a hierarchy; never skip a level.
  • Modify a style once and every paragraph using it updates.
  • Heading styles power the Navigation Pane, the table of contents and accessibility.

Check your understanding

A colleague makes headings by setting the text to bold, 16 pt. What will not work in their document?

The Navigation Pane will be empty and an automatic table of contents cannot be built, because Word does not recognise those paragraphs as headings.

You want all Heading 2 text to be dark green. What is the efficient method?

Right-click Heading 2 in the Styles gallery, choose Modify and set the colour. Every Heading 2 updates at once.

How can you move a whole chapter to a different place without cutting and pasting?

Drag its heading to the new position in the Headings tab of the Navigation Pane.
