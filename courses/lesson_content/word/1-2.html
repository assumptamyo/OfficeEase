Lesson 1.2

Professional documents are rarely typed from start to finish; they are assembled from existing material. This lesson covers the tools that move content and formatting efficiently: the Clipboard, Paste Special, the Format Painter and the finer paragraph controls.

Learning objectives

By the end of this lesson you will be able to:

  • choose the correct paste option for a given situation;
  • use the Office Clipboard to collect and paste several items;
  • copy formatting from one piece of text to another with the Format Painter;
  • set indents, tab stops and pagination options for a paragraph.

Cut, copy and paste

The three basic commands are Ctrl + X (cut), Ctrl + C (copy) and Ctrl + V (paste). What matters is how the content arrives. After every paste Word shows a small Paste Options button; the choice you make there decides whether the text keeps its old appearance or adopts the new one.

Paste optionWhat it doesWhen to use it
Keep Source FormattingKeeps the original font, colour and layoutThe pasted item must look exactly as it did, such as a quoted table
Merge FormattingAdopts the surrounding style but keeps bold and italicBringing text into a report while preserving emphasis
Keep Text OnlyRemoves all formatting and pastes plain textCopying from web pages, emails or PDFs
TipText copied from a website usually brings hidden fonts, colours and spacing with it. Paste it as Keep Text Only and format it yourself; the document stays consistent.

Paste Special

Press Ctrl + Alt + V to open the Paste Special dialog box. It lists every format in which the copied content can be pasted: formatted text, unformatted text, a picture, or a linked object. Choosing Paste link for an Excel range, for example, keeps the Word table connected to the workbook so that it updates when the figures change.

The Office Clipboard

The ordinary clipboard remembers only the last item copied. The Office Clipboard stores up to 24 items. Open it with the dialog box launcher in the Clipboard group; each item you copy is added to the pane, and you can click any item to paste it or choose Paste All.

It is the right tool when gathering several extracts from a long source document: copy them all in one pass, then paste them where they belong.

The Format Painter

The Format Painter copies formatting, not text. It is the fastest way to make one heading look exactly like another.

  1. Click in, or select, the text whose formatting you want to copy.
  2. Click Format Painter in the Clipboard group. The pointer becomes a paintbrush.
  3. Drag across the text that should receive the formatting.

A single click works once. Double-click the Format Painter to lock it on so you can paint many pieces of text in succession; press Esc when you have finished. The keyboard equivalents are Ctrl + Shift + C to copy formatting and Ctrl + Shift + V to apply it.

Advanced paragraph options

The dialog box launcher in the Paragraph group opens settings that give precise control over layout.

First line indent
Moves only the first line of the paragraph to the right, as in a novel.
Hanging indent
Leaves the first line in place and indents the rest. It is the standard layout for reference lists.
Tab stops
Fixed positions that text jumps to when you press Tab. They align columns of text reliably; the space bar does not.
Keep with next
Prevents a page break between this paragraph and the following one, so a heading never sits alone at the bottom of a page.
Widow/Orphan control
Stops a single line of a paragraph being stranded at the top or bottom of a page.
Common mistakeUsing the Format Painter on body text when a Style would be better. The Format Painter copies formatting once; if you later change your mind, every piece must be repainted. Styles, covered in Module 4, update everywhere at once.

Worked example: assembling a briefing note

  1. Open the Office Clipboard, then copy three paragraphs from different source documents.
  2. In the new document, paste each one and choose Keep Text Only so that all three match.
  3. Format the first sub-heading as bold, 14 pt, dark blue.
  4. With the cursor in that sub-heading, double-click the Format Painter, click each remaining sub-heading, then press Esc.

Key takeaways

  • Ctrl + Alt + V opens Paste Special; Keep Text Only is the safest choice for outside content.
  • The Office Clipboard holds up to 24 items.
  • Double-clicking the Format Painter locks it for repeated use; Esc turns it off.
  • Indents, tab stops and pagination options replace manual spacing and manual page breaks.

Check your understanding

You paste a paragraph from a web page and it arrives in a grey font with odd spacing. What should you have chosen?

Keep Text Only, which strips the web formatting so the text takes on the formatting of your document.

How do you apply one heading's formatting to six other headings without re-clicking the button each time?

Double-click the Format Painter to lock it, click each heading, then press Esc.

Which paragraph option keeps a heading on the same page as the text that follows it?

Keep with next, on the Line and Page Breaks tab of the Paragraph dialog box.
