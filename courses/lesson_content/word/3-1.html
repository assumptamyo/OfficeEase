Lesson 3.1

Formatting one paragraph at a time does not scale to a forty-page report. The Design tab works at the level of the whole document: one decision changes every heading, colour and font together, which is how organisations keep their documents visually consistent.

Learning objectives

By the end of this lesson you will be able to:

  • explain what a theme controls and how it differs from a style set;
  • change the colour palette and font pair of a document;
  • add a text or picture watermark;
  • apply page colour and page borders appropriately.

Themes: the design system of a document

A theme is a coordinated set of three things:

Theme colours
A palette of text, background and six accent colours. Styles, tables, charts and shapes draw their colours from it.
Theme fonts
A pair of fonts: one for headings and one for body text.
Theme effects
The shadows, lines and fills applied to shapes and SmartArt.

Choose a theme from Design > Themes. Because headings, tables and charts all refer to the theme, changing it restyles the entire document in one click. The same themes exist in Excel and PowerPoint, so a report, its workbook and its slides can share one look.

ImportantA theme only changes content that uses theme colours and theme fonts. Text you coloured manually with a Standard Colour, or set in a specific font by hand, will not change. This is one reason to format with styles rather than by hand.

Style sets, colours and fonts

The Document Formatting gallery on the Design tab lists style sets. A style set changes how the built-in styles (Title, Heading 1, Normal and so on) look: their size, spacing, capitalisation and borders.

ControlWhat it changesExample
ThemesColours, fonts and effects togetherOffice, Facet, Integral

When you have a combination you want to reuse, choose Set as Default and every new blank document will start with it.

Watermarks

A watermark is faint text or a faint picture printed behind the content of every page. It states the status of a document, such as DRAFT or CONFIDENTIAL, without obstructing the text.

  1. Choose Design > Watermark.
  2. Pick a ready-made watermark, or choose Custom Watermark.
  3. For a text watermark, type the wording and choose the font, colour and whether it runs diagonally or horizontally. Keep Semitransparent ticked.
  4. For a picture watermark, select the image file and keep Washout ticked so that it stays pale.

To delete it, choose Design > Watermark > Remove Watermark.

Page colour and page borders

Page Color fills the background of every page. It is intended for documents read on screen; by default Word does not print it, which saves ink.

Page Borders draws a frame around the page. In the dialog box you choose the style, colour and width of the line, and under Apply to whether it appears on the whole document, one section or the first page only. A border suits certificates, invitations and cover pages.

TipIn formal business and academic documents, restraint reads as professionalism. Use one theme, at most two accent colours, and reserve page borders for cover pages and certificates.

Worked example: branding a draft report

  1. Apply the Office theme from Design > Themes.
  2. Open Colors and choose Blue Warm; all headings and tables change colour together.
  3. Open Fonts and choose a pair with a distinct heading font.
  4. Add a custom text watermark reading DRAFT, diagonal and semitransparent.

Key takeaways

  • A theme controls colours, fonts and effects for the whole document.
  • A style set controls how headings and body paragraphs are styled.
  • A watermark places faint text or a picture behind the content of every page.
  • Manually formatted text ignores theme changes.

Check your understanding

Which feature adds "CONFIDENTIAL" or "DRAFT" behind the document content?

A watermark, from Design > Watermark.

You change the theme, but one heading keeps its old red colour. What is the likely cause?

That heading was coloured manually with a standard colour, so it no longer follows the theme.

You want different heading sizes and spacing but the same colours. Which control do you use?

A style set from the Document Formatting gallery, which restyles the built-in styles without changing the palette.
