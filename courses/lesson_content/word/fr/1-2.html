Leçon 1.2

Les documents professionnels sont rarement dactylographiés du début à la fin ; ils sont assemblés à partir de matériel existant. Cette leçon couvre les outils qui déplacent efficacement le contenu et le formatage : le Presse-papiers, le Collage spécial, le Format Painter et les contrôles de paragraphe plus fins.

Objectifs d'apprentissage

À la fin de cette leçon, vous serez capable de :

  • choisissez l'option de collage correcte pour une situation donnée ;
  • utilisez le Presse-papiers Office pour collecter et coller plusieurs éléments ;
  • copier le formatage d'un morceau de texte à un autre avec Format Painter ;
  • définir les retraits, les taquets de tabulation et les options de pagination pour un paragraphe.

Couper, copier et coller

Les trois commandes de base sont Ctrl + X (couper), Ctrl + C (copier) et Ctrl + V (coller). Ce qui compte, c'est comment le contenu arrive. Après chaque collage, Word affiche un petit bouton Options de collage ; le choix que vous y faites décide si le texte conserve son ancienne apparence ou adopte la nouvelle.

AstuceLe texte copié à partir d’un site Web comporte généralement des polices, des couleurs et des espacements cachés. Collez-le sous Conserver le texte uniquement et formatez-le vous-même ; le document reste cohérent.

Collage spécial

Appuyez sur Ctrl + Alt + V pour ouvrir la boîte de dialogue Collage spécial. Il répertorie tous les formats dans lesquels le contenu copié peut être collé : texte formaté, texte non formaté, image ou objet lié. Choisir Coller le lien pour une plage Excel, par exemple, maintient la table Word connectée au classeur afin qu'elle soit mise à jour lorsque les chiffres changent.

Le presse-papiers Office

Le presse-papiers ordinaire ne mémorise que le dernier élément copié. Le OfficePresse-papiers stocke jusqu'à 24 éléments. Ouvrez-le avec le lanceur de boîte de dialogue dans le groupe Presse-papiers ; chaque élément que vous copiez est ajouté au volet et vous pouvez cliquer sur n'importe quel élément pour le coller ou choisir Coller tout.

C'est l'outil idéal pour rassembler plusieurs extraits d'un long document source : copiez-les tous en un seul passage, puis collez-les à leur place.

Le peintre de formats

Le Format Painter copie le formatage, pas le texte. C’est le moyen le plus rapide de faire en sorte qu’un titre ressemble exactement à un autre.

  1. Cliquez ou sélectionnez le texte dont vous souhaitez copier la mise en forme.
  2. Cliquez sur Format Painter dans le groupe Presse-papiers. Le pointeur devient un pinceau.
  3. Faites glisser le texte qui doit recevoir la mise en forme.

Un simple clic fonctionne une fois. Double-cliquez sur Format Painter pour le verrouiller afin de pouvoir peindre plusieurs morceaux de texte successivement ; appuyez sur Esc lorsque vous avez terminé. Les équivalents clavier sont Ctrl + Shift + C pour copier le formatage et Ctrl + Shift + V pour l'appliquer.

Options de paragraphe avancées

Le lanceur de boîte de dialogue du groupe Paragraphe ouvre les paramètres qui donnent un contrôle précis sur la mise en page.

Retrait de première ligne
Déplace uniquement la première ligne du paragraphe vers la droite, comme dans un roman.
Retrait suspendu
Laisse la première ligne en place et met le reste en retrait. Il s'agit de la présentation standard des listes de références.
Taquets de tabulation
Correction des positions auxquelles le texte passe lorsque vous appuyez sur Tab. Ils alignent les colonnes de texte de manière fiable ; la barre d'espace ne le fait pas.
Continuer avec le suivant
Empêche un saut de page entre ce paragraphe et le suivant, afin qu'un titre ne reste jamais seul au bas d'une page.
Contrôle des veuves/orphelins
Empêche qu'une seule ligne d'un paragraphe soit bloquée en haut ou en bas d'une page.
Erreur couranteUtiliser Format Painter sur le corps du texte lorsqu'un Style serait préférable. Format Painter copie le formatage une fois ; si vous changez d'avis plus tard, chaque pièce doit être repeinte. Les styles, abordés dans le module 4, sont mis à jour partout en même temps.

Exemple concret : assemblage d'une note d'information

  1. Ouvrez le Presse-papiers Office, puis copiez trois paragraphes à partir de documents sources différents.
  2. Dans le nouveau document, collez chacun d'eux et choisissez Conserver le texte uniquement pour que les trois correspondent.
  3. Formatez le premier sous-titre en gras, 14 pt, bleu foncé.
  4. Avec le curseur dans ce sous-titre, double-cliquez sur Format Painter, cliquez sur chaque sous-titre restant, puis appuyez sur Esc.

Points clés à retenir

  • Ctrl + Alt + V ouvre le collage spécial ; Conserver le texte uniquement est le choix le plus sûr pour le contenu extérieur.
  • Le Presse-papiers Office peut contenir jusqu'à 24 éléments.
  • Un double-clic sur Format Painter le verrouille pour une utilisation répétée ; Esc le désactive.
  • Les retraits, les taquets de tabulation et les options de pagination remplacent l’espacement manuel et les sauts de page manuels.

Vérifiez votre compréhension

Vous collez un paragraphe à partir d’une page Web et il arrive dans une police grise avec un espacement impair. Qu'aurais-tu dû choisir ?

Conserver le texte uniquement, qui supprime la mise en forme Web afin que le texte prenne la mise en forme de votre document.

Comment appliquer la mise en forme d'un titre à six autres titres sans re-cliquer sur le bouton à chaque fois ?

Double-cliquez sur Format Painter pour le verrouiller, cliquez sur chaque en-tête, puis appuyez sur Échap.

Quelle option de paragraphe conserve un titre sur la même page que le texte qui le suit ?

Continuez avec suivant, dans l'onglet Sauts de ligne et de page de la boîte de dialogue Paragraphe.
