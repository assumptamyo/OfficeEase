Lesson 5.2

A finished design is valuable only if it can be reused and delivered. This lesson shows how to build custom layouts for your own kinds of slide, save the result as a template, and export a presentation in the format that suits each audience.

Learning objectives

By the end of this lesson you will be able to:

  • create and name a custom layout with placeholders;
  • save a presentation as a reusable template;
  • choose the correct export format for a given purpose;
  • check a presentation before distributing it.

Custom layouts

The built-in layouts cover common cases. When your presentations repeatedly need something else, such as a case study with a photograph, a quotation and three statistics, build a layout for it once.

  1. Open View > Slide Master.
  2. Choose Insert Layout. A new layout appears, inheriting from the parent master.
  3. Choose Insert Placeholder, select a type and drag to draw it on the layout.
  4. Right-click the layout thumbnail and choose Rename Layout. Give it a name that describes its purpose, such as Case Study.
  5. Close Master View. The layout is now listed under Home > New Slide.
Placeholder typeAccepts
ContentAnything: text, table, chart, SmartArt, picture or video
TextText only
PictureA picture, which is cropped automatically to fill the frame
Chart / Table / SmartArt / MediaThat type of object only
TipA Picture placeholder guarantees that every photograph on that layout has the same size and position, whoever builds the slide. It is the most useful placeholder for a shared template.

Saving a template

A template stores the slide master, layouts, theme and any starter slides so that new presentations begin with the design already in place.

  1. Delete any slides that should not be part of every new presentation.
  2. Choose File > Save As and set the file type to PowerPoint Template (*.potx).
  3. Save it in the suggested Custom Office Templates folder so that it appears under File > New > Personal.

Opening a .potx file creates a new, untitled presentation based on it. The template itself is left unchanged, so it cannot be overwritten by accident.

Export formats

Different audiences need different files. Most of these are found under File > Export or File > Save As.

FormatExtensionUse it when
PowerPoint Presentation.pptxThe file will be edited or presented in PowerPoint. The normal working format.
PowerPoint Template.potxThe design is to be reused as the starting point for new presentations.
PowerPoint Show.ppsxThe file should open directly in slide show mode when double-clicked.
PDF.pdfSharing a fixed copy for reading or printing. Layout and fonts are preserved, but animations and video are lost.
Video.mp4The presentation must play by itself, with timings, narration and animations, on any device.
Picture.png / .jpgIndividual slides are needed as images, for example for social media.

For printed material, File > Print offers Handouts (several slides per page, with space for notes) and Notes Pages (one slide per page with its speaker notes).

Before you distribute

  • Check Accessibility. Review > Check Accessibility finds missing alt text, poor contrast and an unclear reading order.
  • Inspect Document. File > Info > Check for Issues > Inspect Document finds and removes speaker notes, comments and personal information you may not want to share.
  • Compress Media. File > Info > Compress Media reduces the size of embedded video.
  • Embed fonts if the presentation uses non-standard fonts and will be opened on another computer.
ImportantSpeaker notes are part of the .pptx file. If you email the presentation, the recipient can read them. Remove them with Inspect Document, or send a PDF instead.

Worked example: delivering a client template

  1. In Slide Master view, insert a new layout and add a Picture placeholder on the left and a Text placeholder on the right. Rename it Case Study.
  2. Close Master View and create one sample slide from each layout.
  3. Run Check Accessibility and correct anything reported.
  4. Save the file as Brand_Master_Template.potx.
  5. Export a PDF of the sample slides to send to the client for approval.

Key takeaways

  • Custom layouts are built in Slide Master view with Insert Layout and Insert Placeholder.
  • A reusable template is saved with the extension .potx.
  • Use .pptx for editing, .pdf for a fixed copy, .mp4 for a self-running video and .ppsx to open straight into the show.
  • Check accessibility and inspect the document before sending it.

Check your understanding

Which file extension is used when saving a presentation as a reusable template?

.potx.

A client needs to read your slides on a phone and must not be able to change them. Which format do you send?

PDF. It preserves the layout and fonts and is not easily edited.

What is lost when a presentation is exported to PDF?

Animations, transitions, video and audio. Each slide becomes a static page.
