Lesson 3.2

A bulleted list tells the audience that items exist; a diagram shows how they relate. This lesson covers SmartArt for turning lists into diagrams, icons for visual shorthand, and video and audio for the moments when a slide should show rather than tell.

Learning objectives

By the end of this lesson you will be able to:

  • convert a bulleted list into a SmartArt graphic of the appropriate type;
  • edit and restyle a SmartArt graphic;
  • insert and recolour icons;
  • insert video and audio and set their playback options.

What SmartArt is for

SmartArt is a diagram that PowerPoint draws and keeps tidy for you. You supply the text; it supplies the shapes, the spacing and the alignment, and rearranges everything when an item is added or removed.

The quickest route is to start from text you already have. Right-click a bulleted list and choose Convert to SmartArt. The list is instantly transformed into a visual diagram. Alternatively, start from an empty diagram with Insert > SmartArt.

Choosing the right type

The type must match the relationship between the items. Choosing by appearance alone produces diagrams that mislead.

CategoryShowsExample
ListItems of equal weight in no particular orderCompany values, product features
ProcessSteps that happen in sequenceResearch → Design → Build → Test
CycleA sequence that repeatsPlan, do, check, act
HierarchyLevels of authority or classificationAn organisation chart
RelationshipConnections or overlaps between ideasA Venn diagram
MatrixParts of a whole in quadrantsA SWOT analysis
PyramidProportions or levels that build on each otherLevels of priority

Editing SmartArt

  • Text pane. Click the arrow on the left edge of the graphic. Each line of text is a shape: Enter adds a shape, Tab demotes it to a lower level and Shift + Tab promotes it. This is how the levels of an organisation chart are built.
  • SmartArt Design tab. Layouts switches to another diagram type while keeping the text; Change Colors applies a palette from the theme; SmartArt Styles changes the finish.
  • Convert. SmartArt Design > Convert > Convert to Shapes turns the diagram into ordinary shapes that can be edited and animated individually.
TipKeep each item to a few words. SmartArt shrinks the text of every shape to fit the longest entry, so one long line makes the whole diagram hard to read.

Icons

Insert > Icons opens a library of simple pictograms. Icons are vector graphics: they are described by lines and curves rather than pixels, so they stay sharp at any size. Recolour one with Graphics Format > Graphics Fill to match the theme.

Use icons consistently: the same style and size throughout, each paired with a short label. An icon without a label is often ambiguous.

Video and audio

Insert media with Insert > Video or Insert > Audio. A file from This Device is embedded in the presentation, so it travels with the file and needs no internet connection. Selecting the media opens the Playback tab.

Playback optionEffect
Start: In Click Sequence / Automatically / When Clicked OnDecides what makes the media begin
Trim VideoPlays only the part between a chosen start and end point
Play Full ScreenExpands the video to fill the screen while it plays
Fade In / Fade OutSoftens the beginning and end
Loop until StoppedRepeats the media, useful for background displays
Play Across Slides (audio)Continues the sound over the following slides
ImportantEmbedded video makes the file large, and online video fails without a connection. Test all media on the actual computer and room equipment before presenting, including the sound.

Worked example: from list to diagram

  1. Type four bullet points: Research, Design, Build, Test.
  2. Right-click the list, choose Convert to SmartArt and select a Process layout.
  3. Open the Text pane and add a fifth step, Launch; the diagram resizes itself.
  4. Choose Change Colors and pick a palette from the theme.
  5. Insert an icon above each step and recolour the icons to match.

Key takeaways

  • Convert to SmartArt turns a bulleted list into a diagram instantly.
  • Match the SmartArt category to the relationship: process, cycle, hierarchy and so on.
  • Icons are vector graphics that can be recoloured and resized without loss of quality.
  • Embedded media travels with the file; set how it starts on the Playback tab and always test it.

Check your understanding

Which feature instantly transforms a plain bulleted list into a visual diagram?

Convert to SmartArt.

Which SmartArt category suits a company's reporting structure?

Hierarchy, which shows levels such as an organisation chart.

You need only 20 seconds from the middle of a two-minute video. Which option do you use?

Trim Video on the Playback tab, setting the start and end points.
