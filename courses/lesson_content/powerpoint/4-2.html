Lesson 4.2

An animation controls when and how a single object appears, changes or leaves while a slide is on screen. Its real purpose is not decoration but pacing: revealing information at the moment the speaker reaches it, so the audience is never reading ahead.

Learning objectives

By the end of this lesson you will be able to:

  • name the four categories of animation and their purpose;
  • set the start, duration and delay of an animation;
  • sequence several animations with the Animation Pane;
  • copy animations with the Animation Painter and use them with restraint.

The four categories

Select an object and open the gallery on the Animations tab. The effects are colour-coded.

CategoryColourPurposeExamples
EntranceGreenHow an object appears on the slideAppear, Fade, Fly In, Wipe
EmphasisYellowDraws attention to an object already visiblePulse, Spin, Grow/Shrink
ExitRedHow an object leaves the slideDisappear, Fade, Fly Out
Motion PathsLinesMoves an object along a routeLines, Arcs, Custom Path

To give one object a second effect, for example an entrance followed by an exit, use Add Animation. Choosing from the main gallery again would replace the first effect.

Timing

The Timing group determines when each animation runs.

Start: On Click
The animation waits for the presenter to click or press a key. Use it when you want to control the moment of each reveal.
Start: With Previous
The animation runs at exactly the same moment as the animation before it. Use it to make several objects move together.
Start: After Previous
The animation runs automatically as soon as the previous one has finished. Use it to chain effects without clicking.
Duration
How long the effect takes. Around 0.5 seconds feels brisk and professional.
Delay
A pause before the effect begins, measured from its start trigger.

Small numbers beside objects on the slide show the click on which each animation runs. Animations set to With Previous or After Previous share the number of the click that triggers them.

The Animation Pane

Choose Animations > Animation Pane to see every animation on the slide as a list, in running order, with a bar showing its timing.

  • Reorder by dragging an entry up or down.
  • Adjust timing by dragging the ends of a bar.
  • Open Effect Options by double-clicking an entry, for settings such as sound, or dimming text after it has been shown.
  • Play From previews the sequence.

For a bulleted list, Effect Options > By Paragraph makes each point appear separately, which is the standard technique for revealing a list one item at a time.

TipThe Animation Painter copies the animation of one object to another, in the same way that the Format Painter copies formatting. Double-click it to apply the animation to several objects in turn.

Using animation with judgement

  • Animate only when it helps understanding: revealing steps in order, or building up a diagram.
  • Prefer simple effects such as Fade, Appear and Wipe. Bouncing and spinning effects distract.
  • Use the same effect for the same kind of object throughout.
  • Keep effects fast. An audience waiting for text to arrive loses patience quickly.
Common mistakeSetting every point to On Click and then having to click twenty times on one slide. Reveal points on click, but group the supporting details With Previous or After Previous.

Worked example: revealing a four-point list

  1. Select the text placeholder containing four bullet points and apply the Fade entrance.
  2. Open Effect Options and choose By Paragraph. The numbers 1 to 4 appear beside the points.
  3. Leave Start as On Click so that each point appears when you are ready to discuss it.
  4. Select the icon beside the list, apply Fade and set its Start to With Previous, so that it arrives together with the first point.
  5. Open the Animation Pane and click Play From to check the sequence.

Key takeaways

  • Entrance (green), Emphasis (yellow), Exit (red) and Motion Paths are the four categories.
  • On Click waits for the presenter; With Previous runs at the same moment as the previous animation; After Previous follows it.
  • The Animation Pane lists, reorders and times the animations on a slide.
  • Animation should control pacing, not decorate.

Check your understanding

Which timing setting makes an animation run at exactly the same moment as the one before it?

With Previous.

Which category of animation would you use to draw attention to a figure that is already on the slide?

Emphasis, shown in yellow, such as Pulse or Grow/Shrink.

You want an object to fade in and later fade out. Why must you use Add Animation for the second effect?

Choosing an effect from the main gallery replaces the existing animation. Add Animation gives the object an additional one.
