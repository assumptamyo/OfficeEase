Lesson 5.1

So far every formula has calculated the same way for every row. The IF function lets a formula make a decision: it asks a question about the data and returns one result if the answer is yes and another if it is no. It is the basis of all automated judgement in Excel.

Learning objectives

By the end of this lesson you will be able to:

  • write a logical test using the comparison operators;
  • state the three arguments of the IF function;
  • build IF formulas that return text, numbers or calculations.

Logical tests

A logical test is a comparison whose answer can only be TRUE or FALSE. It is built with a comparison operator.

OperatorMeaningExampleIf C2 is 60
=Equal toC2=60TRUE
<>Not equal toC2<>60FALSE
>Greater thanC2>60FALSE
<Less thanC2<60FALSE
>=Greater than or equal toC2>=60TRUE
<=Less than or equal toC2<=60TRUE
Common mistakeConfusing > with >=. If the pass mark is 60, a student with exactly 60 passes only if the test is C2>=60. Always check the boundary value.

The IF function

=IF(logical_test, value_if_true, value_if_false)

logical_test
The question, for example C2>=60.
value_if_true
What the cell shows when the test is TRUE.
value_if_false
What the cell shows when the test is FALSE.

Read the commas aloud as "then" and "otherwise". =IF(C2>=60, "Pass", "Fail") reads: if C2 is at least 60, then Pass, otherwise Fail.

What IF can return

ReturnsExampleMeaning
Text=IF(B2>0, "In stock", "Out of stock")A label describing the stock level
A number=IF(D2>=1000, 50, 0)A fixed bonus of 50 for large orders
A calculation=IF(D2>=1000, D2*10%, D2*2%)10% commission on large sales, 2% otherwise
Nothing=IF(E2<TODAY(), "Overdue", "")Flags late items and leaves the rest blank
ImportantText inside a formula must be in double quotation marks: "Pass". Numbers must not be: "50" is text and cannot be added up later. Two quotation marks with nothing between them, "", mean an empty result.
TipAvoid typing thresholds into the formula. Put the pass mark in a cell such as G1 and write =IF(C2>=$G$1, "Pass", "Fail"). Changing the pass mark then means editing one cell, not every formula.

Worked example: exam results

  1. Enter student marks out of 100 in C2:C20.
  2. In D2 type =IF(C2>=50, "Pass", "Fail") and press Enter.
  3. Double-click the fill handle to copy the formula down.
  4. Change one mark from 49 to 50. The result changes from Fail to Pass immediately.

Key takeaways

  • A logical test compares two values and is either TRUE or FALSE.
  • IF has three arguments: the test, the result if true, the result if false.
  • Text results need quotation marks; numbers do not.
  • Check the boundary: > and >= give different answers at the threshold.

Check your understanding

What does =IF(A1>100, "High", "Normal") return when A1 contains 100?

"Normal". 100 is not greater than 100, so the test is FALSE.

Name the three arguments of IF in order.

The logical test, the value if true, and the value if false.

Why is =IF(B2>10, "5", "0") a poor way to return a bonus amount?

The quotation marks make 5 and 0 text, so they cannot be used in later calculations such as SUM.
