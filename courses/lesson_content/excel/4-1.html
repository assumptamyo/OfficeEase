Lesson 4.1

A block of cells with headings looks like a table, but to Excel it is only a range. Declaring it an official Excel Table changes how it behaves: it grows by itself, formats itself and lets formulas refer to columns by name.

Learning objectives

By the end of this lesson you will be able to:

  • convert a data range into an Excel Table and name it;
  • explain the advantages of a table over an ordinary range;
  • add a Total Row and a calculated column;
  • read and write structured references.

Preparing the data

A table needs tidy data. Before converting a range, check that:

  • the first row contains a unique heading for every column;
  • each row describes one item (one sale, one employee, one product);
  • there are no completely blank rows or columns inside the data;
  • there are no merged cells.

Creating a table

  1. Click any single cell inside the data.
  2. Press Ctrl + T, or choose Insert > Table.
  3. Check the range Excel has detected, make sure My table has headers is ticked, and click OK.
  4. On the Table Design tab, replace the default name (Table1) with a meaningful one such as InventoryTable. Table names cannot contain spaces.

What a table gives you

FeatureBenefit
Banded rowsAlternate rows are shaded automatically, and stay correct when rows are added or sorted
Filter buttonsEvery heading gains a drop-down arrow for sorting and filtering
Automatic expansionType in the row below or the column beside the table and it becomes part of the table
Calculated columnsEnter a formula in one cell and it fills the whole column
Sticky headingsWhen you scroll, the column letters are replaced by the table headings
Total RowA summary row with a choice of function for each column

Automatic expansion is the most valuable of these. Charts, PivotTables and formulas built on a table include new rows the moment they are added, so reports never fall out of date because someone forgot to extend a range.

The Total Row

Tick Table Design > Total Row, or press Ctrl + Shift + T. A row appears beneath the table. Click a cell in it and choose from the drop-down list: Sum, Average, Count, Max, Min and others.

TipThe Total Row counts only the rows that are visible. Filter the table to one region and the total becomes the total for that region.

Structured references

Inside a table, formulas use column names instead of cell addresses. These are structured references.

Structured referenceMeaning
=[@Quantity]*[@Price]Quantity times Price in this row. The @ sign means "this row".
=SUM(Sales[Amount])The total of the whole Amount column of the table named Sales
=AVERAGE(Sales[Amount])The average of that column

Compare =SUM(Sales[Amount]) with =SUM(E4:E50). The first states what it calculates and remains correct when the table grows to row 500; the second does neither.

NoteTo turn a table back into an ordinary range, choose Table Design > Convert to Range. The formatting stays but the table behaviour is removed.

Worked example: a stock list

  1. Click inside the data in A3:E50 and press Ctrl + T.
  2. Name the table InventoryTable on the Table Design tab.
  3. In the first empty column type the heading Value, then =[@Quantity]*[@Price]. The whole column fills.
  4. Turn on the Total Row and set the Value column to Sum.
  5. Type a new product in the row beneath the table and watch the total include it.

Key takeaways

  • Ctrl + T converts a range into an Excel Table.
  • Tables expand automatically, so everything built on them stays up to date.
  • A formula typed once becomes a calculated column.
  • Structured references use table and column names instead of cell addresses.

Check your understanding

Which shortcut converts a selected range into an Excel Table?

Ctrl + T.

In the formula =[@Hours]*[@Rate], what does the @ sign mean?

"This row": the formula uses the Hours and Rate values from the same row as the formula.

Why is a chart based on a table more reliable than one based on the range A1:D20?

The table expands when rows are added, so the chart includes the new data automatically. A fixed range would have to be extended by hand.
