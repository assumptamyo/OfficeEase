Lesson 5.2

Real decisions rarely rest on one condition. A bonus may require high sales and long service; a discount may apply to members or to large orders; a grade has five possible outcomes. This lesson extends IF with AND, OR, nesting and the IFS function.

Learning objectives

By the end of this lesson you will be able to:

  • combine conditions with AND and OR and predict the result;
  • use AND or OR as the logical test of an IF;
  • write a nested IF and the equivalent IFS formula;
  • choose the clearest function for a given decision.

AND and OR

Both functions take several logical tests and return a single TRUE or FALSE.

AND(test1, test2, …)
TRUE only if every test is true. One false test makes the whole result FALSE.
OR(test1, test2, …)
TRUE if at least one test is true. It is FALSE only when every test is false.

Using AND and OR inside IF

AND and OR are placed where the logical test of an IF would normally go.

=IF(AND(B2>10000, C2>2), B2*10%, B2*2%)
pays 10% commission only when sales exceed 10,000 and service exceeds two years; otherwise 2%.

=IF(OR(B2>=50000, C2>=4.8), "Bonus", "No bonus")
awards a bonus when either the sales target or the customer rating is met.

Work through an example by evaluating the inside first. In =IF(AND(10>5, 2>8), "Yes", "No"), the first test is TRUE but the second is FALSE. AND needs both, so it returns FALSE, and the IF returns "No".

Nested IF

An IF can only choose between two outcomes. For more, a second IF is placed in the value_if_false position of the first. This is nesting.

=IF(C2>=80, "A", IF(C2>=65, "B", IF(C2>=50, "C", "F")))

Excel tests the conditions from left to right and stops at the first that is true. A mark of 70 fails the first test, passes the second, and returns B.

ImportantOrder matters. Test the highest threshold first. If the formula began with C2>=50, every mark of 50 or more, including 95, would return C and the later tests would never be reached. Each nested IF also needs its own closing bracket, which is where most errors occur.

The IFS function

IFS expresses the same logic as pairs of test, result in a single function, with no nesting.

=IFS(C2>=80, "A", C2>=65, "B", C2>=50, "C", TRUE, "F")

Like nested IF, it returns the result of the first test that is true. The final pair, TRUE, "F", is the catch-all: TRUE is always true, so anything not matched earlier receives F. Without it, a mark below 50 would produce the error #N/A.

The main advantage of IFS is clarity: it removes the deeply nested closing brackets and makes a long chain of conditions readable.

Worked example: performance tiers

  1. With sales in B2 and customer rating in C2, enter =IF(OR(B2>=50000, C2>=4.8), "Eligible", "Not eligible") in D2.
  2. In E2 enter =IFS(B2>=100000, "Gold", B2>=50000, "Silver", TRUE, "Bronze").
  3. Fill both formulas down the list.
  4. Test the boundaries: try sales of exactly 50,000 and exactly 100,000 and confirm the tier is the one you intended.

Key takeaways

  • AND is true only when all tests are true; OR is true when at least one is.
  • Place AND or OR in the logical test of IF to decide on several conditions.
  • In nested IF and IFS, the first true test wins, so order the tests from the most demanding down.
  • IFS avoids nested brackets; end it with TRUE as a catch-all.

Check your understanding

What does =IF(AND(10>5, 2>8), "Yes", "No") return?

"No". The second test is false, so AND returns FALSE.

What is the main advantage of IFS over nested IF?

It removes the need for deeply nested closing brackets, so the formula is easier to read and maintain.

What would the same formula return if AND were replaced by OR?

"Yes". OR needs only one true test, and 10>5 is true.
