Lesson 1.1

Excel is a grid, and everything it does, from a shopping list to a company budget, depends on being able to say exactly where a piece of data lives. This lesson introduces the grid, the way cells are addressed, and how to move around a worksheet with confidence.

Learning objectives

By the end of this lesson you will be able to:

  • name the parts of the Excel window and state what each one shows;
  • read and write cell and range references;
  • move to any cell quickly with the mouse, the keyboard and the Name Box.

The grid: columns, rows and cells

Column
A vertical strip of the grid, identified by a letter: A, B, C … Z, then AA, AB and so on up to XFD (16,384 columns).
Row
A horizontal strip, identified by a number from 1 to 1,048,576.
Cell
The box where one column meets one row. A cell holds a single value: a number, some text, a date or a formula.
Active cell
The cell currently selected, shown with a thick green border. Whatever you type goes into it.

Cell references

Every cell has an address called a cell reference, written as the column letter followed by the row number. The cell where column D meets row 10 is D10: letter first, number second, with nothing in between.

A rectangular block of cells is a range. It is written as its top-left cell and its bottom-right cell separated by a colon.

ReferenceMeaning
D10The single cell in column D, row 10
A1:A5Five cells in column A, rows 1 to 5
A1:C3A block three columns wide and three rows deep (nine cells)
B:BThe whole of column B
3:3The whole of row 3
Common mistakeWriting the row first (10D) or adding punctuation (D-10). Excel only understands the form letter then number.

The parts of the window

Name Box
The small box at the left, above column A. It displays the address of the active cell. Type a reference into it and press Enter to jump straight to that cell.
Formula Bar
The long box to the right of the Name Box. It shows the true contents of the active cell: if the cell displays 150 but contains =100+50, the Formula Bar shows the formula.
Ribbon
The tabs of commands across the top: Home, Insert, Formulas, Data and others.
Status Bar
The strip at the bottom. Select several numbers and it instantly reports their Sum, Average and Count.
TipThe grid shows the result; the Formula Bar shows the recipe. When a number looks wrong, click the cell and read the Formula Bar.

Moving around

KeysMovement
Arrow keysOne cell in that direction
Ctrl + arrow keyTo the edge of the current block of data
Ctrl + HomeTo cell A1
Ctrl + EndTo the last cell that contains data
Ctrl + G or F5Opens Go To, where you type a reference
Shift + arrow keyExtends the selection by one cell

Worked example: finding your way

  1. Click in the Name Box, type C5 and press Enter. The active cell moves to C5.
  2. Type OfficeEase Test and press Enter. The text is stored in C5.
  3. Click C5 again and look at the Formula Bar: it shows the same text, confirming the contents.
  4. Press Ctrl + Home to return to A1.

Key takeaways

  • A cell reference is the column letter followed by the row number, such as D10.
  • A range is written with a colon, such as A1:C3.
  • The Name Box shows the address of the active cell; the Formula Bar shows its contents.

Check your understanding

What is the reference of the cell where column D meets row 10?

D10. The column letter always comes first.

Which part of the window displays the address of the active cell?

The Name Box, at the left above column A.

How many cells are in the range B2:C4?

Six: two columns (B and C) by three rows (2, 3 and 4).
