Lesson 3.2

Relative references are convenient until a formula must always point to one particular cell, such as a tax rate. This lesson introduces the absolute reference, which fixes a cell in place, and the core functions that summarise a range of numbers.

Learning objectives

By the end of this lesson you will be able to:

  • decide when a reference must be absolute and create one with F4;
  • describe the structure of a function and its arguments;
  • use SUM, AVERAGE, MIN, MAX, COUNT and COUNTA correctly.

The problem absolute references solve

Suppose a tax rate of 8% is stored in cell C1 and the revenue for each product is in D3:D10. In E3 you write =D3*C1, which is correct. Copied down one row it becomes =D4*C2: the revenue reference moved correctly, but the tax reference moved too and now points at an empty cell.

A dollar sign locks the part of the reference it precedes. $C$1 means "always column C, always row 1", wherever the formula is copied. The correct formula is =D3*$C$1.

The four reference types

While typing or editing a reference, press F4 to cycle through the four forms.

ReferenceTypeWhen copied
A1RelativeColumn and row both change
$A$1AbsoluteNothing changes
A$1Mixed (row locked)The column changes, the row stays 1
$A1Mixed (column locked)The row changes, the column stays A
Rule of thumbAsk: "When I copy this formula, should this reference move with it?" If yes, leave it relative. If it must stay on one fixed cell, such as a rate, a target or an exchange rate, make it absolute.

What a function is

A function is a ready-made calculation with a name. It is written as the name followed by its arguments in brackets:

=SUM(B3:B10)

Here SUM is the function and the range B3:B10 is its argument. Several arguments are separated by commas, as in =SUM(B3:B10, D3:D10). As you type a function name Excel offers a list of matches; press Tab to accept one.

The core functions

FunctionReturnsExample
SUMThe total of the numbers=SUM(E3:E10)
AVERAGEThe arithmetic mean=AVERAGE(E3:E10)
MINThe smallest number=MIN(E3:E10)
MAXThe largest number=MAX(E3:E10)
COUNTHow many cells contain numbers=COUNT(E3:E10)
COUNTAHow many cells are not blank, whatever they contain=COUNTA(A3:A10)

The difference between COUNT and COUNTA matters. In a column containing 10, 20, "absent" and 40, COUNT returns 3 because it counts only the numeric cells, while COUNTA returns 4 because it counts every cell that is not empty. Use COUNTA to count names; use COUNT to count scores.

Common mistakeAVERAGE ignores empty cells but includes zeros. A blank cell for an absent student and a zero for a failed one give different averages. Decide which you mean.
TipClick below a column of numbers and press Alt + =. AutoSum writes the SUM formula and guesses the range for you.

Worked example: sales tax on each line

  1. Type the tax rate 0.08 in cell C1.
  2. In E3 type =D3*C1, then with the cursor on C1 press F4 once. The formula becomes =D3*$C$1.
  3. Press Enter and fill the formula down to E10.
  4. Click E10: it reads =D10*$C$1. The revenue reference moved; the tax reference did not.
  5. In E11 enter =SUM(E3:E10) for the total tax collected.

Key takeaways

  • A dollar sign locks the column, the row or both; F4 cycles through the options.
  • Use an absolute reference for any single cell that many formulas depend on.
  • A function is a name followed by arguments in brackets.
  • COUNT counts numeric cells only; COUNTA counts all non-blank cells.

Check your understanding

Which key converts A1 into $A$1 while you are editing a formula?

F4. Pressing it again cycles through A$1, $A1 and back to A1.

A range contains 5, 8, "N/A" and an empty cell. What do COUNT and COUNTA return?

COUNT returns 2, the two numbers. COUNTA returns 3, the three cells that are not blank.

The formula =B2*$F$1 is copied from C2 to C6. What does it become?

=B6*$F$1. The relative reference moves down four rows; the absolute reference stays on F1.
